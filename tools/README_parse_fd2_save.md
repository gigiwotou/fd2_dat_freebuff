# FD2.SAV 解析工具使用说明

## 概述

`parse_fd2_save.py` 是用于解析炎龙骑士团2存档文件(FD2.SAV)的Python工具。
它根据IDA Pro MCP反汇编分析结果，1:1还原了游戏的数据结构。

## 功能特性

- 自动解密XOR滚动加密的存档文件
- 验证校验和完整性
- 解析营地存档数据（共享区12501字节）
- 解析4个战场临时存档槽位（每槽位2600字节）
- 解析角色信息（图标ID、职业、阵营、位置、道具等）
- 可选解析FDFIELD.DAT地图数据
- 可选解析FDTXT.DAT文本资源

## 使用方法

### 基本用法

```bash
python parse_fd2_save.py <FD2.SAV文件>
```

### 完整用法

```bash
python parse_fd2_save.py <FD2.SAV文件> [FDFIELD.DAT文件] [FDTXT.DAT文件]
```

### 示例

```bash
# 解析存档文件
python parse_fd2_save.py FD2.SAV

# 解析存档 + 地图数据
python parse_fd2_save.py FD2.SAV FDFIELD.DAT

# 解析存档 + 地图数据 + 文本资源
python parse_fd2_save.py FD2.SAV FDFIELD.DAT FDTXT.DAT
```

## 技术细节

### 文件结构
```
FD2.SAV (22987字节)
├── 营地地图数据 (0-2210, 2211字节)
├── 营地战场队伍数据 (2211-4770, 2560字节)
├── 角色数据 (4771-12450, 7680字节, 96角色×80字节)
├── 图标缓存 (12451-12482, 32字节)
├── 营地游戏状态 (12483-12500, 18字节)
├── 未使用区域 (12501-12586, 86字节)
├── 战场存档槽位0 (12587-15186, 2600字节)
├── 战场存档槽位1 (15187-17786, 2600字节)
├── 战场存档槽位2 (17787-20386, 2600字节)
├── 战场存档槽位3 (20387-22982, 2600字节)
└── 校验和 (22983-22986, 4字节)
```

### 加密算法
```python
key = 0xA5
for i in range(22987):
    key = ROL((key - 0x7014), 3)
    data[i] ^= (key & 0xFF)
```

### 校验和算法
```python
checksum = 0
for i in range(22983):
    checksum += data[i]
checksum &= 0xFFFFFFFF
```

## 测试工具

`create_test_save.py` 用于创建测试存档文件，验证解析器的正确性。

```bash
python create_test_save.py
```

这将生成3个测试存档：
- `test_save_1.sav` - 基本存档，无战场存档
- `test_save_2.sav` - 包含战场存档
- `test_save_3.sav` - 更多角色的存档

## 注意事项

1. 在Windows上运行时，如果控制台使用GBK编码，中文可能会显示为乱码。
   建议使用UTF-8终端（如Windows Terminal、PowerShell等）。

2. 道具名称、职业名称、种族名称是基于游戏数据手动整理的，可能与实际游戏有差异。

3. FDTXT.DAT和FDFIELD.DAT是可选的，如果文件不存在，解析器会跳过相关信息的解析。
