# FDTXT.DAT 文本资源分析

## 1. 文件概述
FDTXT.DAT是游戏的文本资源文件，包含游戏中所有场景需要显示的对话文本和消息。该文件采用索引表+数据的结构，通过索引号访问不同的文本数据块。

## 2. 加载逻辑

### 2.1 加载函数
FDTXT.DAT使用`sub_111BA`函数加载，该函数的加载流程为：
1. 释放旧资源指针（如果存在）
2. 以"rb"模式打开FDTXT.DAT文件
3. 计算索引表位置：`fseek(fp, 4 * index + 6, SEEK_SET)`
4. 读取索引项（4字节offset, 4字节size）
5. 计算资源大小：`dword_53BFF = size - offset`
6. 分配内存并读取资源数据
7. 关闭文件并返回资源指针

### 2.2 加载点分析

#### 2.2.1 主函数加载 (main, 0x25d07)
```c
dword_53A7D = sub_111BA((int)aFdtxtDat, dword_53A7D, 0); // "FDTXT.DAT"
```
- **加载索引**: 0
- **用途**: 游戏启动时加载默认文本资源
- **存储变量**: `dword_53A7D` (全局变量)

#### 2.2.2 存档加载函数 (sub_10010, 0x101f6)
```c
n17 = *(unsigned __int8 *)(v0 + 12485); // 从存档读取n17值
dword_53A79 = sub_111BA(aFdtxtDat, dword_53A79, n17 + 1); // "FDTXT.DAT"
```
- **加载索引**: `n17 + 1`（动态索引）
- **用途**: 加载存档对应的关卡文本
- **存储变量**: `dword_53A79` (全局变量)
- **说明**: n17是存档数据中的关卡编号，+1因为索引0可能保留给默认文本

#### 2.2.3 关卡切换函数 (sub_1088D, 0x108c4)
```c
dword_53A79 = sub_111BA((int)aFdtxtDat, dword_53A79, n13 + 1); // "FDTXT.DAT"
```
- **加载索引**: `n13 + 1`（动态索引）
- **用途**: 切换关卡时加载对应文本资源
- **存储变量**: `dword_53A79` (全局变量)
- **说明**: n13是当前关卡编号参数

## 3. 数据结构

### 3.1 文件结构
FDTXT.DAT采用以下结构：
```
[文件头 6字节]
[索引表项0: 4字节offset, 4字节size]
[索引表项1: 4字节offset, 4字节size]
...
[数据块0]
[数据块1]
...
```

### 3.2 数据块内部结构
每个数据块包含一系列文本项，每个文本项的结构为：
```
[文本ID: 2字节]
[文本偏移: 2字节]
[文本数据]
```

文本数据以特殊控制字符开头：
- `-1` (0xFFFF): 文本块结束标记
- `-2` (0xFFFE): 换行控制
- `-3` (0xFFFD): 换行+清除状态
- `-4` (0xFFFC): 递归调用dword_53A7D的文本
- `-5` (0xFFFB): 递归调用dword_53ADD的文本
- `-6` (0xFFFA): 显示数值（dword_53AE1）
- `-17` (0xFFEF): 加载头像(正面)
- `-18` (0xFFEE): 加载头像(侧面)
- `-19` (0xFFED): 从dword_53A45加载角色头像(正面)
- `-20` (0xFFEC): 从dword_53A45加载角色头像(侧面)

## 4. 使用场景

### 4.1 文本渲染核心函数 (sub_15F84)
这是所有文本渲染的核心函数，原型：
```c
void __usercall sub_15F84(
    unsigned __int8 *a1@<edi>,  // 目标显存地址
    int a2,                      // 文本资源指针 (dword_53A79 或 dword_53A7D)
    int a3,                      // 文本项索引
    int n658255,                 // 初始屏幕偏移 (通常658255或693535)
    int a5,                      // 屏幕宽度 (320)
    int a6,                      // 渲染参数1 (205)
    int a7,                      // 渲染参数2 (76)
    int a8,                      // 渲染参数3 (74)
    int a9,                      // 行间距 (19)
    int a10                      // 动画标志 (1)
)
```

**处理流程**：
1. 解析索引表：`v11 = (__int16 *)(*(short *)(a2 + 2 * a3) + a2)`
2. 循环读取文本项直到遇到-1结束标记
3. 根据控制码执行不同操作：
   - 普通字符：调用`sub_4ED7A`渲染字符（使用dword_53A75字体）
   - 换行(-2/-3)：调整屏幕偏移`n658255_1 = ++n3 * a9 * a5 + n658255`
   - 数值显示(-6)：格式化`dword_53AE1`为字符串并逐字符显示
   - 头像加载(-17/-18/-19/-20)：从DATO.DAT或dword_53A45加载角色头像

## 7. 与其他资源的协同

### 7.1 与FDOTHER.DAT的关系
- **FDOTHER.DAT索引4** (dword_53A75): 用于字符渲染字体资源
- FDTXT.DAT中的文本通过`sub_4ED7A`函数使用dword_53A75的字体数据来显示每个字符

### 7.2 与DATO.DAT的关系
- 文本中的控制码`-17`/`-18`会触发DATO.DAT头像资源的加载
- 用于在对话中显示角色头像

### 7.3 与FDFIELD.DAT的关系
- FDTXT.DAT和FDFIELD.DAT通常同时加载（相同关卡索引）
- FDFIELD.DAT提供地图数据，FDTXT.DAT提供该关卡的文本数据

### 7.4 与FDSHAP.DAT的关系
- 文本渲染时可能需要FDSHAP.DAT的形状数据
- 用于UI元素的渲染

## 8. 渲染流程总结

1. **加载阶段**：
   - 根据关卡编号`n`，加载FDTXT.DAT索引`n+1`的数据块
   - 存储到全局变量`dword_53A79`

2. **解析阶段**：
   - 通过`sub_15F84`函数解析文本数据块
   - 读取索引表找到文本项位置
   - 循环处理文本项直到遇到结束标记(-1)

3. **渲染阶段**：
   - 普通字符：使用dword_53A75字体资源渲染
   - 控制码：执行换行、显示数值、加载头像等操作
   - 每行间距由参数a9控制（通常19像素）

4. **显示位置**：
   - 初始偏移通常为658255或693535（对应VGA显存地址）
   - 屏幕宽度320像素

## 9. 关键发现

1. **双文本系统**：游戏使用两个文本资源指针
   - `dword_53A7D`: 固定索引0的全局文本（选项、错误信息等）
   - `dword_53A79`: 动态索引的关卡文本（剧情对话等）

2. **索引偏移+1**：关卡文本索引 = 关卡编号 + 1，可能索引0保留给全局文本

3. **丰富的控制码**：支持换行、数值显示、头像加载、递归调用等功能

4. **与存档系统关联**：存档数据中包含关卡编号(n17)，用于加载对应文本

5. **文本与场景强关联**：不同场景（战斗、收集、对话、升级）使用不同的文本索引范围
