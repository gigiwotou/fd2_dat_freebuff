# FD2.EXE (炎龙骑士团2) 绘制框架分析

## 📋 基本信息

- **文件名**: FD2.EXE
- **图形模式**: VGA 320x200 256色 (模式13h)
- **显存地址**: 0xA0000 (655360十进制)
- **调色板**: VGA DAC, 端口968/969
- **分析工具**: IDA Pro MCP Server

***

## 🎨 绘制框架架构

### 1. 渲染管道

```
数据加载 → 缓冲处理 → 元素渲染 → 调色板设置 → 屏幕刷新
   ↓           ↓          ↓          ↓           ↓
 文件读取   双缓冲    文本/图形   VGA DAC    垂直同步
```

### 2. 双缓冲系统

**缓冲区布局**:

- **主缓冲区 (VGA显存)**: 地址 655360 (0xA0000)
- **后备缓冲区**: 地址 n655360\_0
- **临时缓冲区**: 通过malloc动态分配

**页面翻转流程**:

```c
// 1. 后备缓冲 → 主缓冲
memmove(655360, n655360_0, 64000);

// 2. 格式转换 (320字节/行 → 456字节/行)
for (n200 = 0; n200 < 200; ++n200)
    memmove(456*(n200-4) + n655360 + 32900, 
            &n655360_0[320*n200], 320);

// 3. 渲染到后备缓冲
// ... 各种绘制函数 ...

// 4. 等待垂直同步
while (!sub_10620());  // 检查键盘输入同时等待

// 5. 刷新屏幕
sub_11D40(...);  // 更新调色板
```

## 🖼️ 核心绘制函数

### 1. 文本/UI渲染引擎 - sub\_15F84()

**地址**: 0x15F84\
**大小**: 0x564 (1380字节)

**功能**: 解析文本数据格式并渲染到屏幕

#### 1.1 文本数据格式

特殊标记值:

| 标记值 | 含义    | 处理方式                     |
| --- | ----- | ------------------------ |
| -1  | 文本结束  | 返回调用者                    |
| -2  | 换行    | 行偏移增加                    |
| -3  | 字体切换  | 切换字集                     |
| -4  | 递归调用1 | 递归渲染FDTXT\_DAT\_\_0索引410 |
| -5  | 递归调用2 | 递归渲染FDTXT\_DAT\_\_0索引513 |
| -6  | 数字显示  | 格式化显示n999\_1             |
| -17 | 图片加载1 | 加载DATO.DAT, 偏移1832       |
| -18 | 图片加载2 | 加载DATO.DAT, 偏移36887      |
| -19 | 动态图片1 | 从场景数据加载图片                |
| -20 | 动态图片2 | 从场景数据加载图片                |
| 其他  | 字符索引  | 渲染对应字符                   |

#### 1.2 函数签名

```c
void sub_15F84(
    unsigned __int8 *a1,        // edi: 当前场景数据指针
    __int32 a2,                 // eax: FDTXT_DAT__0

    int a4,                     // ecx: 其他参数

```

### 2. 正向位块传输 - sub\_4EBFF()

**地址**: 0x4EBFF

**功能**: 从左到右绘制图像 (标准BitBlt)

**函数签名**:

```c
void sub_4EBFF(
    _BYTE *dest,      // 目标缓冲区地址
    __int16 *source,  // 源图像数据 [宽, 高, 像素数据...]
    int lineSpan      // 目标行跨度 (通常320)
);
```

**实现代码**:

```c
void sub_4EBFF(_BYTE *dest, __int16 *source, int lineSpan) {
    __int16 width = source[0];   // 图像宽度
    __int16 height = source[1];  // 图像高度
    
    do {
        _BYTE *rowStart = dest;
        int x = width;
        do {
            char pixel = sub_4EC66();  // 获取下一个像素
            *dest++ = pixel;           // 从左到右写入
            --x;
        } while (x);
        dest = &rowStart[lineSpan];  // 下一行
        --height;
    } while (height);
}
```

**特点**:

- 逐行从左到右写入像素
- 支持任意尺寸图像
- 自动处理行跨度

### 3. 反向位块传输 - sub\_4EC31()

**地址**: 0x4EC31

**功能**: 从右到左绘制图像 (镜像效果)

**函数签名**:


**实现代码**:

```c
void sub_4EC31(_BYTE *dest, __int16 *source, int lineSpan) {
    __int16 width = source[0];   // 图像宽度
    __int16 height = source[1];  // 图像高度
    
    do {
        _BYTE *rowStart = dest;
        int x = width;
        do {
            char pixel = sub_4EC66();  // 获取下一个像素
            *dest-- = pixel;           // 从右到左写入 (镜像)
```

**特点**:

- 与sub\_4EBFF类似,但像素写入方向相反
- 用于实现水平镜像效果
- 相同的图像数据可以正向/反向绘制

### 4. 字符/精灵渲染 - sub\_4ED7A()

**地址**: 0x4ED7A

**功能**: 从FDOTHER.DAT加载字形数据并渲染16x16字符

**函数签名**:

```c
void sub_4ED7A(
    int fdotherData,    // FDOTHER.DAT数据基址
    int charIndex,      // 字符索引 (0-255)
    int screenOffset,   // 屏幕偏移
    unsigned __int16 lineSpan,  // 行跨度
    char fgColor,       // 前景色
    char bgColor,       // 背景色
    int flags           // 标志
);
```

**实现代码**:

```c
void sub_4ED7A(
    int fdotherData,
    int charIndex,
    int screenOffset,
    unsigned __int16 lineSpan,
    char fgColor,
    char bgColor,
    int flags
) {
    FDOTHER_DAT__1 = fdotherData;
    n10_2 = charIndex;
    ::n658255 = screenOffset;
    ::argC = lineSpan;
    ::arg10 = fgColor;
    ::arg14 = bgColor;
    ::arg18 = flags;
    
    // 如果flags非零, 先填充背景
    if ((BYTE)flags) {
        int fillColor = (flags << 16) | (flags & 0xFFFF);
        char *screenPtr = (char *)::n658255;
        char height = 16;
        do {
            memset32(screenPtr, fillColor, 4u);  // 填充16字节
            screenPtr += lineSpan;
            --height;
        } while (height);
    }
    
    // 渲染字符 (如果不是空格)
    if (charIndex != 10) {  // 10可能是空格索引
        __int16 *glyphData = (__int16*)(32 * charIndex + FDOTHER_DAT__1);
        char *screenPtr = (char *)::n658255;
        char arg10_1 = ::arg10;  // 前景色
        char arg14_1 = ::arg14;  // 背景色
        char height = 16;
        
        do {
            __int16 row = *glyphData++;  // 获取一行字形数据 (16位)
            
            // 字节交换
            char rowHi = HIBYTE(row);
            char rowLo = LOBYTE(row);
            row = (rowHi << 8) | rowLo;
            
            char *linePtr = screenPtr;
            char width = 16;
            
            do {
                // 检查最高位
                bool carry = __CFSHL__(row, 1);  // 左移, 检查进位
                row *= 2;
                
                if (carry) {
                    // 位为1: 使用前景色/背景色
                    *screenPtr = arg10_1;        // 前景
                    screenPtr[lineSpan - 1] = arg14_1;  // 背景 (右边缘)
                    screenPtr[lineSpan] = arg14_1;      // 背景 (下一行)
                }
                ++screenPtr;
                --width;
            } while (width);
            
            screenPtr = &linePtr[lineSpan];  // 下一行
            --height;
        } while (height);
    }
}
```

**工作原理**:

1. 从FDOTHER.DAT加载字形数据 (每个字符32字节 = 16行 × 2字节/行)
2. 每行16位, 每位对应一个像素
3. 位为1: 使用前景色
4. 位为0: 使用背景色 (或透明)
5. 支持16×16字符尺寸

### 5. VGA调色板设置 - sub\_11D40()

**地址**: 0x11D40

**功能**: 通过VGA DAC端口设置调色板颜色

**函数签名**:

```c
void sub_11D40(
    __int32 a1,     // eax: 参数
    int a2, a3, a4, // 其他参数
    int startColor, // 起始颜色索引 (0-255)
    int endColor,   // 结束颜色索引
    int colorOffset // 颜色偏移量
);
```

**实现代码**:

```c
void sub_11D40(..., int startColor, int endColor, int colorOffset) {
    sub_3702F(..., 24);
    
    while (startColor <= endColor) {
        // 设置DAC写地址寄存器
        outp(968, startColor);
        
        // 写入红色分量
        int red = *(unsigned __int8*)(FDOTHER_DAT + 3*startColor) - colorOffset;
        if (red < 0) red = 0;
        outp(969, red);
        
        // 写入绿色分量
        int green = *(unsigned __int8*)(FDOTHER_DAT + 3*startColor + 1) - colorOffset;
        if (green < 0) green = 0;
        outp(969, green);
        
        // 写入蓝色分量
        int blue = *(unsigned __int8*)(FDOTHER_DAT + 3*startColor + 2) - colorOffset;
        if (blue < 0) blue = 0;
        outp(969, blue);
        
        ++startColor;
    }
}
```

**VGA DAC寄存器说明**:

- **端口968 (0x3C8)**: DAC写地址寄存器
- **端口969 (0x3C9)**: DAC颜色数据寄存器 (RGB)

**颜色格式**:

- 每个分量6位 (0-63)
- 每个颜色占用3个连续索引: R, G, B
- FDOTHER.DAT存储原始RGB值

**用途**:

- 设置游戏调色板
- 实现淡入淡出效果 (调整colorOffset)
- 动态颜色动画

## 🎯 关键技术点

### 1. 显存布局

```
VGA显存 (0xA0000)
├─ 偏移 0-63999: 320x200 像素数据
├─ 偏移 32900-693535: 456字节/行格式
└─ 偏移 655360: 显存基址 (十进制)
```

### 2. 行跨度转换

**为什么从320转换为456?**

- 320: 实际像素宽度
- 456: 包含额外数据的行跨度 (可能用于特殊效果或对齐)
- 转换公式: `456 * (行号 - 4) + 32900`

### 3. 颜色系统

**VGA调色板**:

- 256色调色板
- 每个颜色: 6位R + 6位G + 6位B (0-63)
- 通过端口968/969编程

**颜色使用**:

- 前景色: 205 (文本)
- 背景色: 76 (阴影)
- 动态调整: 淡入淡出效果

### 4. 垂直同步

```c
while (!sub_10620()) {
    // 等待垂直回扫
    // 同时检查键盘输入
}
```

- 防止画面撕裂
- 60Hz刷新率
- 每帧约16.67ms

### 5. 动画帧率控制

- 使用DOS定时器 (MEMORY\[0x46C])
- 每秒18.2个滴答
- 每2-4个滴答更新一帧
- 实际帧率: 约4.5-9 FPS
