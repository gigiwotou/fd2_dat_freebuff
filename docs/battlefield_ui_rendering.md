## 二、函数详细分析

### 2.1 sub_12D7B (0x12D7B) - 角色信息面板入口

**原型**: `int __fastcall sub_12D7B(__int32 a1, int a2, int a3, int a4, int a5)`

**功能**: 角色属性界面入口函数

**参数**:
- `a5`: 角色索引

**流程**:
1. 调用 `sub_3702F(..., 12)` - 初始化上下文
2. 获取角色数据: `*(u8*)(80 * a5 + dword_53A45)`
   - `dword_53A45` 是角色数据数组基地址
   - 每个角色数据 **80字节**
3. 获取角色方向/等级: `*(u8*)(80 * a5 + dword_53A45 + 1)`
4. 调用 `sub_12CEA(角色类型, 角色方向/等级)`

**关键汇编**:
```asm
12d89  mov     eax, edx          ; eax = a5
12d8b  shl     eax, 2            ; eax = a5 * 4
12d8e  add     edx, eax          ; edx = a5 * 5
12d90  shl     edx, 4            ; edx = a5 * 80
12d93  mov     eax, dword_53A45  ; 角色数据基地址
12d98  add     eax, edx          ; eax = 角色数据指针
12d9a  movzx   edx, byte ptr [eax]     ; 角色类型 (byte+0)
12d9d  movzx   eax, byte ptr [eax+1]   ; 角色方向/等级 (byte+1)
12da3  call    sub_12CEA
```

### 2.2 sub_12CEA (0x12CEA) - 面板主循环

**原型**: `void __fastcall sub_12CEA(__int32 a1, int a2, int a3, int a4, int a5, int a6)`

**功能**: 面板渲染主循环，处理滚动逻辑

**参数**:
- `a1-a4`: 上下文参数
- `a5`: 垂直滚动控制参数
- `a6`: 水平滚动控制参数

**流程**:
1. 调用 `sub_3702F(..., 20)` - 初始化上下文
2. 调用 `sub_11CAC(0)` - 渲染单帧面板
3. **垂直滚动循环** (`while a5 != n9_0`):
   - 如果 `a5 >= n9_0`: 调用 `sub_11BFA(v6)`
   - 否则: 调用 `sub_11C59(v6)`
   - 等待输入: `v6 = sub_4E381()`
4. **水平滚动循环** (`while a6 != n34_0`):
   - 如果 `a6 >= n34_0`: 调用 `sub_11B9B(v6)`
   - 否则: 调用 `sub_11B48()`
   - 等待输入: `v6 = sub_4E381()`

### 2.3 sub_11CAC (0x11CAC) - 核心渲染函数

**原型**: `int __fastcall sub_11CAC(__int32 a1, int a2, int a3, int a4, int a5)`

**功能**: 单帧面板渲染核心函数

**参数**:
- `a1-a4`: 上下文参数
- `a5`: 是否跳过sub_4E31C (0=执行, 1=跳过)

**完整渲染流程**:

```c
// 1. 准备数据
v5 = sub_3702F(a1, a2, a3, a4, 32);

// 2. 处理数据
sub_1297D(v5);

// 3. 可选: 更新调色板
if (!a5)
    sub_4E31C();

// 4. 渲染文字 (8行 x 13列，每字符24像素宽)
sub_11EEE(dword_53A49 + 32904, 456, 13, 8, n9, n34);

// 5. 获取信息数据
v6 = sub_122DC();

// 6. 渲染信息
sub_127A9(v6);

// 7. 绘制边框
sub_1ACF3(dword_53A49 + 32904, 456);

// 8. 拷贝到屏幕 (312x192区域)
return sub_11EB0(656644, 320, dword_53A49 + 32904, 456, 312, 192);
```

**关键常量**:
- 内部缓冲区基地址: `dword_53A49 + 32904` (0x8088)
- 缓冲区步长: `456`
- 面板宽度: `312`
- 面板高度: `192`
- 目标屏幕地址: `656644` (0xA0504, VGA显存)
- 屏幕步长: `320`

### 2.4 sub_11EEE (0x11EEE) - 文字渲染核心函数

**原型**: `void __cdecl sub_11EEE(int a1, int a2, int a3, int a4, int a5, int a6)`

**功能**: 使用FDSHAP.DAT精灵渲染文字到缓冲区

**参数**:
- `a1`: 目标缓冲区偏移 (通常为0，最终地址为dword_53A49+32904)
- `a2`: 缓冲区步长 = **456**
- `a3`: 每行字符数 = **13**
- `a4`: 字符行数 = **8**
- `a5`: 垂直滚动偏移 (`n9`)
- `a6`: 水平滚动偏移 (`n34`)

**完整渲染逻辑**:

#### 2.4.1 预渲染切换逻辑
```c
switch (n17) {
    case 9, 24, 25, 28, 29:
        // 背景动画渲染
        sub_4EEE0(dword_53AFF, dword_53B03, dword_539FC);
        sub_11EB0(..., dword_53B03, 320, 312, 192);
        break;
    case 17, 21, 22, 27:
        // 不同宽度的背景渲染 (462或408)
        n462 = (n17==17 || n17==27) ? 462 : 408;
        sub_11EB0(..., 3*a5 + dword_53AFF + ..., n462, 312, 192);
        break;
    case 23:
        sub_24D22(0);
        sub_11EB0(..., dword_53AFF, 312, 312, 192);
        break;
}
```

#### 2.4.2 调色板映射准备
```c
// 字符数据表基地址
v15 = dword_53A6D + *(DWORD*)(dword_53A6D + 4 * byte_51A97[dword_53C1F] + 6);
```

#### 2.4.3 字符渲染主循环
```c
// 双重循环：外层遍历行(v14: 0..a4-1)，内层遍历列(i: 0..a3-1)
for (v14 = 0; v14 < a4; v14++) {
    // 计算字符数据指针
    v7 = dword_53A51 + 4 * (a5 + dword_53AC1 * (a6 + v14)) + 4;
    
    // 计算目标缓冲区位置 (每字符24像素宽)
    v8 = 24 * a2 * v14 + a1;
    
    for (i = 0; i < a3; i++) {
        // 获取字符精灵索引 (10位)
        v11 = *(WORD*)v7 & 0x3FF;
        
        // 获取字符标志
        v13 = *(BYTE*)(4 * v11 + dword_53A69);
        
        // 检查标志位
        if (v13 & 8) break;  // 停止标志
        
        if (v13 & 0x10) {
            // 中心对齐偏移
            v11 += n3_1 / 2;
        }
        
        if (v13 & 4) {
            // 调色板偏移
            v11 += dword_53A40;
        }
        
        // 获取FDSHAP.DAT精灵数据
        v12 = FDSHAP_DAT + *(DWORD*)(FDSHAP_DAT + 4 * v11 + 6);
        
        // 根据调色板索引选择渲染方式
        if (*(BYTE*)(v7 + 3) == 255) {
            // 直接blit (无调色板映射)
            sub_4E22A(v12, v8, a2);
        } else {
            // 带调色板映射blit
            sub_4E016(v12, v8, a2, v15);
        }
        
        // 移动到下一个字符位置
        v7 += 4;
        v8 += 24;  // 每个字符宽24像素
    }
}
```

**关键数据结构**:

- `dword_53A51`: 字符布局数据表指针
  - 每个条目 **4字节**
  - 格式: `[索引(10位) | 调色板索引(8位) | 保留(14位)]`
  - 布局: `4 * (a5 + dword_53AC1 * (a6 + v14)) + 4`

- `dword_53A69`: 字符标志表
  - 每条目4字节
  - 标志位:
    - `bit 2 (0x4)`: 需要调色板偏移
    - `bit 3 (0x8)`: 停止标志
    - `bit 4 (0x10)`: 中心对齐

- `FDSHAP_DAT`: FDSHAP.DAT资源基地址
  - 格式: `[头(6字节) | 精灵偏移表...]`
  - 每个精灵: `*(DWORD*)(FDSHAP_DAT + 4 * v11 + 6)` 获取数据指针

- `dword_53A6D`: 调色板映射表基地址
  - 用于sub_4E016的调色板颜色转换

### 2.5 sub_122DC (0x122DC) - 信息数据准备

**原型**: `int sub_122DC()`

**功能**: 根据 `dword_51A83` 状态准备信息渲染数据

**关键逻辑**:
```c
switch (dword_51A83) {
    case 1:  // 基本状态
        return sub_126F7(n9_0, n34_0, 0);
    case 2:
        return sub_126F7(n9_0, n34_0, 1);
    case 3:  // 攻击范围
        sub_126F7(n9_0, n34_0, 14);
        sub_126F7(n9_0, n34_0 - 1, 2);
        sub_126F7(n9_0 - 1, n34_0, 3);
        sub_126F7(n9_0 + 1, n34_0, 4);
        return sub_126F7(n9_0, n34_0 + 1, 5);
    case 4:  // 更大范围
        sub_126F7(n9_0, n34_0, 1);
        sub_126F7(n9_0, n34_0 - 2, 2);
        // ... 更多位置
    case 5:  // 最大范围
        // ... 大量位置设置
    case 6:
        result = n9_0 + dword_53AC1 * n34_0;
        *(BYTE*)(dword_53A51 + 4 * result + 7) = 0;
}
```

## 五、字符/精灵渲染机制

### 5.1 字符索引获取
```
字符索引 = *(WORD*)(dword_53A51 + 4 * (a5 + dword_53AC1 * (a6 + v14)) + 4) & 0x3FF
```

### 5.2 FDSHAP精灵数据获取
```c
精灵数据指针 = FDSHAP_DAT + *(DWORD*)(FDSHAP_DAT + 4 * 索引 + 6)
```

### 5.3 精灵渲染函数

#### sub_4E22A (直接blit)
- 24x24像素精灵
- RLE解码
- 直接拷贝到目标缓冲区
- 参数: `sub_4E22A(精灵数据, 目标位置, 步长)`

#### sub_4E016 (带调色板映射)
- 24x24像素精灵
- RLE解码 + 调色板颜色转换
- `*(a4 + 像素值)` 进行颜色映射
- 参数: `sub_4E016(精灵数据, 目标位置, 步长, 调色板映射)`

## 六、角色数据结构 (80字节)

从sub_12D7B的汇编可知:
```
byte+0:  角色类型 (0=友军, 1=敌军, 2=NPC)
byte+1:  角色方向/等级
byte+2:  未知
...
byte+7:  角色ID/图标

从sub_10010分析:
*(BYTE*)(80*i + dword_53A45 + 2) = sub_11019(*(BYTE*)(80*i + dword_53A45 + 7), v14);
```

## 八、实现要点

1. **渲染缓冲区**: 456步长, 32904偏移
2. **字符渲染**: 从dword_53A51获取字符索引, 从FDSHAP_DAT获取24x24精灵
3. **精灵渲染**: sub_4E22A(直接) 或 sub_4E016(带调色板映射)
4. **屏幕拷贝**: sub_11EB0 (456步长 -> 320步长, 312x192区域)
5. **角色数据**: 80字节/角色, 存储在dword_53A45
