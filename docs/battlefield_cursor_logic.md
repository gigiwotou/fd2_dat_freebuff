## 一、概述

战场地图中有一个由方向键控制的光标，用于选择地图上的角色或事件对象。光标以瓦片为单位在地图上移动，并触发相应的交互逻辑。

## 五、滚动机制详解

### 5.1 滚动偏移与移动计数器

游戏使用**双缓冲滚动机制**：

| 变量 | 作用 |
|------|------|
| dword_53AA9 | 水平滚动偏移（屏幕已滚动的列数） |
| dword_53AAD | 垂直滚动偏移（屏幕已滚动的行数） |
| n10 | 水平移动计数器（在可视区域内移动的次数） |
| n2_1 | 垂直移动计数器（在可视区域内移动的次数） |

### 5.2 水平滚动逻辑

```
移动方向：左移
条件判断：
  if (n10 < 2 && dword_53AA9) {
      // 还在可视区域前2列，调整滚动偏移
      --dword_53AB1;
      --dword_53AA9;
  } else {
      // 在可视区域内移动，调整移动计数器
      --dword_53AB1;
      --n10;
  }

移动方向：右移
条件判断：
  if (n10 <= 10 || (dword_53AC1 - 13 == dword_53AA9)) {
      // 在可视区域内或到达滚动边界，调整移动计数器
      ++dword_53AB1;
      ++n10;
  } else {
      // 到达可视区域边缘，调整滚动偏移
      ++dword_53AB1;
      ++dword_53AA9;
  }
```

### 5.3 垂直滚动逻辑

```
移动方向：上移
条件判断：
  if (n2_1 < 2 && dword_53AAD) {
      // 还在可视区域前2行，调整滚动偏移
      --dword_53AB5;
      --dword_53AAD;
  } else {
      // 在可视区域内移动，调整移动计数器
      --dword_53AB5;
      --n2_1;
  }

移动方向：下移
条件判断：
  if (n2_1 <= 5 || (dword_53AC5 - 8 == dword_53AAD)) {
      // 在可视区域内或到达滚动边界，调整移动计数器
      ++dword_53AB5;
      ++n2_1;
  } else {
      // 到达可视区域边缘，调整滚动偏移
      ++dword_53AB5;
      ++dword_53AAD;
  }
```

### 5.4 可视区域大小推断

根据滚动逻辑：
- 水平：`map_width - 13` → 可视区域约**13列**
- 垂直：`map_height - 8` → 可视区域约**8行**

### 14.1 光标结构

typedef struct {
    int x;              // 光标X坐标
    int y;              // 光标Y坐标
    int scroll_x;       // 水平滚动偏移
    int scroll_y;       // 垂直滚动偏移

    int move_counter_y; // 垂直移动计数器
} fd2_cursor_t;

### 14.2 移动函数

```c
void cursor_move_up(fd2_cursor_t* cursor, int map_height) {
    if (cursor->y > 0) {
        if (cursor->move_counter_y < 2 && cursor->scroll_y > 0) {
            cursor->y--;
            cursor->scroll_y--;
        } else {
            cursor->y--;
            cursor->move_counter_y--;
        }
    }
}

void cursor_move_down(fd2_cursor_t* cursor, int map_height) {
    if (cursor->y < map_height - 1) {
        if (cursor->move_counter_y <= 5 || 
            cursor->scroll_y == map_height - 8) {
            cursor->y++;
            cursor->move_counter_y++;
        } else {
            cursor->y++;
            cursor->scroll_y++;
        }
    }
}

void cursor_move_left(fd2_cursor_t* cursor, int map_width) {
    if (cursor->x > 0) {
        if (cursor->move_counter_x < 2 && cursor->scroll_x > 0) {
            cursor->x--;
            cursor->scroll_x--;
        } else {
            cursor->x--;
            cursor->move_counter_x--;
        }
    }
}

void cursor_move_right(fd2_cursor_t* cursor, int map_width) {
    if (cursor->x < map_width - 1) {
        if (cursor->move_counter_x <= 10 || 
            cursor->scroll_x == map_width - 13) {
            cursor->x++;
            cursor->move_counter_x++;
        } else {
            cursor->x++;
            cursor->scroll_x++;
        }
    }
}
```
