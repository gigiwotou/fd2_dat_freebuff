## 二、sub_168B6 - 窗口框架绘制函数

### 2.1 函数定义

**地址**: 0x168B6  
**大小**: 约130字节

**函数头注释**:


### 2.2 参数说明

```c
void __fastcall sub_168B6(
    __int32 a1,    // 源数据指针（tile图集数据）
    int a2,         // 未知（传递给sub_3702F）
    int a3,         // 未知（传递给sub_3702F）
    int a4,         // 未知（传递给sub_3702F）
```

### 2.3 功能分析

该函数负责绘制完整的窗口框架，包括：

- **左右边框**: 循环绘制左侧和右侧边框（索引14-17）
- **内容区域**: 双重循环绘制内部填充tile（索引13）

### 3.2 核心实现

```c
int __fastcall sub_1685C(__int32 a1, int a2, int a3, int a4, int a5, int a6, int a7, int a8)
{
  sub_3702F(a1, a2, a3, a4, 20);  // 入口登记
  // 计算tile数据地址: a7 + 4*a8 + 6 是tile数据指针的偏移表
```

**关键公式**:
- tile数据指针 = `*(DWORD*)(资源基址 + 4*tile索引 + 6) + 资源基址`
- 这是典型的DAT文件资源索引结构

## 四、sub_4ED0B - 像素复制函数

### 4.1 函数定义

**地址**: 0x4ED0B

```c
/*
 * func-name: sub_4ED0B
 * func-address: 0x4ed0b
 * callers: 0x1685c
 * callees: none
 */

void __cdecl sub_4ED0B(char *dst, _WORD *a2, int a3)
{
  unsigned __int16 count; // bp
  char *src; // esi
  __int16 v6; // dx

  count = *a2;        // 每行字节数（宽度）
  src = (char *)(a2 + 2);  // 像素数据起始
  v6 = a2[1];         // 行数（高度）
  do
  {
    qmemcpy(dst, src, count);  // 复制一行
    src += count;              // 下一行源
    dst += a3;                 // 下一行目标（使用行距）
    --v6;
  }
  while (v6);
}
```

### 4.2 数据结构

源数据格式（a2指向的结构）:
```
偏移0: WORD - 宽度（字节数）
偏移2: WORD - 高度（行数）
偏移4: BYTE[] - 像素数据
```

### 4.3 功能说明

这是一个基础的**按行复制blit函数**：
- 按行复制像素数据
- 支持不同的源/目标行距
- 用于将tile从资源缓冲区复制到屏幕缓冲区

## 十一、关键发现

### 11.1 Tile图集索引公式

```c
// 从资源中获取tile数据指针
tile_data_ptr = *(DWORD*)(资源基址 + 4*tile索引 + 6) + 资源基址;
```

这是FD2游戏**统一的资源索引方式**，适用于所有DAT文件。

### 11.2 窗口尺寸模式

游戏使用**预定义的窗口尺寸**：
- 4x2: 小提示框
- 8x3: 角色信息框
- 12x4: 对话中框
- 16x5: 大对话框
- 19x5: 最大对话框

### 11.3 两种对话框类型

根据代码中的`n1832`变量：
- **n1832 = 1832**: 小对话框（使用索引2资源）
- **n1832 = 36887**: 大对话框（使用索引3资源）

### 11.4 文字控制码系统

sub_15F84支持完整的**控制码系统**：
- -1: 结束
- -2/-3: 换行
- -4/-5: 递归子对话框
- -6: 数字输出
- -17至-20: 对话框打开/切换

## 十三、总结

### 13.1 UI绘制系统架构

FD2游戏的UI绘制系统采用**分层设计**：

1. **底层**: sub_4ED0B - 像素复制（blit）
2. **中层**: sub_1685C/sub_16886 - tile绘制（支持RLE压缩）
3. **高层**: sub_168B6 - 窗口框架绘制
4. **文字层**: sub_15F84 - 文字和控制码处理
5. **特效层**: sub_15F0E/sub_187D6 - 特殊效果
