## 一、概述

## 七、总结

1. **Start (选项0)**:
   - 返回值: 0
   - 进入主循环，执行开场剧情场景 (sub_3231B)

   - 使用函数指针表: funcs_25E3A[n17] (从存档恢复)

   - 返回值: != 0,1
   - 调用 sub_10010() 处理特定逻辑
   - 进入主循环

4. **菜单循环**:
   - 上/下方向键选择
   - 确认键 (Enter/Space) 确认
   - 选择后闪烁 4 次
