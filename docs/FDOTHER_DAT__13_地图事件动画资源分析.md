## 五、功能总结

### 5.1 资源内容

`_FDOTHER_DAT__13` (动态索引 n28+33) 存储的是 **地图事件动画 tile 图集**。

### 5.2 具体用途

1. **地图事件动画渲染**
   - 用于在地图上显示事件动画 (NPC、道具、特效等)
   - 支持多帧动画序列

2. **动态资源加载**
   - 每个地图场景加载对应的事件动画资源
   - 索引 = 场景编号 + 33

3. **事件状态显示**
   - 根据事件状态 (dword_540CB, dword_540EE 等) 显示不同帧
   - 支持淡入淡出效果

### 5.3 与其他资源的关系

| 资源 | 用途 | 与 FDOTHER_DAT__13 的关系 |
|------|------|-------------------------|
| BG.DAT | 地图背景 | 作为底层背景 |
| TAI.DAT | 敌人数据 | 与事件动画叠加 |
| FIGANI.DAT | 角色动画 | 与事件动画并行渲染 |
| FDSHAP.DAT | 形状数据 | 用于后续处理 |

## 七、关键发现

### 7.1 动态索引

与大多数静态索引不同，`_FDOTHER_DAT__13` 使用 **动态索引计算**：
- 索引 = n28 (场景编号) + 33
- 这意味着每个地图场景都有自己独立的事件动画资源

### 7.2 资源范围

FDOTHER.DAT 文件中用于事件动画的索引范围：
- **索引 33+**: 各地图场景的事件动画资源
- 根据地图数量，可能占用索引 33-70+ 的范围

### 7.3 动画帧控制

事件动画通过多个计数器控制帧序列：
- `dword_540CB[n3]`: 动画帧计数器
- `dword_540EE[n16]`: 另一组动画帧计数器
- `dword_54018[n10]`: 第三组动画帧计数器
- `dword_54050[n10]`: 第四组动画帧计数器
- `dword_540B0[n2_2]`: 第五组动画帧计数器

### 7.4 与 FDOTHER.DAT 索引13 的区别

注意：虽然变量名叫 `_FDOTHER_DAT__13`，但它**不是**加载文件索引 13。
- `_FDOTHER_DAT__13` 地址 0x54153：加载索引 **n28 + 33** (动态)
- 文件索引 13 在其他地方被加载到 `dword_53F66`
