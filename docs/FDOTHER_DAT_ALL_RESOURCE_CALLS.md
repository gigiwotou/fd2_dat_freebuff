
## 音效资产详细分析

### 索引31 - 主要音效数据

**加载函数**: sub_25A96 (0x25A96)  
**数据格式**: 音频样本数据（无需解密）  
**播放库**: AIL (Audio Interface Library)

#### 音效播放流程

```c
// 音效播放函数
void __fastcall sub_25A96(
    __int32 a1,
    int a2,
    int a3,
    int a4,
    int a5,       // FDOTHER_DAT__2 (音效数据指针)
    int a6,       // 音效索引
    int a7        // 循环次数
)
{
    // 1. 停止当前播放的音效
    sub_39805(v7, dword_53EE4);  // AIL_stop_sample
    
    // 2. 计算音效数据的地址和大小
    v8 = a5 + 4 * a6;
    v13 = *(_DWORD *)(v8 + 6) + a5;   // 音效起始地址
    v12 = *(_DWORD *)(v8 + 10) - *(_DWORD *)(v8 + 6);  // 音效大小
    
    // 3. 初始化音效样本
    sub_39521(v12, dword_53EE4);  // AIL_init_sample
    
    // 4. 设置音效数据地址
    sub_39694(v9, dword_53EE4, v13, v12);  // AIL_set_sample_address
    
    // 5. 设置循环次数
    sub_39AAE(v10, dword_53EE4, a7);  // AIL_set_sample_loop_count
    
    // 6. 开始播放
    sub_39798(v11, dword_53EE4);  // AIL_start_sample
}
```

#### AIL库函数调用

| 函数地址 | AIL函数名 | 功能 |
|----------|-----------|------|
| 0x39805 | AIL_stop_sample | 停止当前音效 |
| 0x39521 | AIL_init_sample | 初始化音效样本 |
| 0x39694 | AIL_set_sample_address | 设置音效数据地址和大小 |
| 0x39AAE | AIL_set_sample_loop_count | 设置循环次数 |
| 0x39798 | AIL_start_sample | 开始播放音效 |

## 资源使用模式分析

### 图像资源加载模式

#### 1. RLE压缩图像 (索引7,8,54,57,59,77,96,97,98,99,101,102)
- **压缩格式**: 自定义RLE压缩
- **解压函数**: sub_4E98D
- **控制字节格式**: 2位操作类型 + 6位计数值
- **操作类型**:
  - 00: 透明跳过 (跳过N个像素)
  - 01: RLE填充 (填充N个相同颜色值)
  - 10: 直接复制 (复制N个原始像素)
  - 11: 双重跳过 (特殊透明处理)

#### 2. 调色板数据 (索引76)
- **格式**: VGA调色板 (256色)
- **写入端口**: 0x3C8 (地址) / 0x3C9 (RGB值)
- **数据大小**: 768字节 (256 * 3)

#### 3. 菜单项资源 (索引69-73)
- **加载方式**: 循环加载5个菜单项
- **显示逻辑**: 根据当前选中状态高亮对应菜单项
- **动画效果**: 支持hover和click状态切换

### 音频资源加载模式

#### 1. 音效数据结构 (索引31)
```c
// 音效目录表结构 (每个条目12字节)
typedef struct {
    DWORD offset;      // 相对于数据区起始的偏移
    DWORD start_addr;  // 实际起始地址 (base + offset)
    DWORD end_addr;    // 结束地址
    DWORD size;        // 音效大小 (end_addr - start_addr)
} SOUND_ENTRY;

// 访问方式
SOUND_ENTRY *entry = &sound_table[index];
BYTE *data = base_ptr + entry->offset;
DWORD size = entry->size;
```

#### 2. 音频格式特性
- **编码**: 未压缩PCM格式
- **加密**: 无需解密，直接读取
- **采样率**: 由AIL库自动检测
- **声道**: 单声道 (Mono)
- **位深**: 8-bit

### 地图资源加载模式

#### 1. 背景图像 (索引15,35,36,40,41,42,46,47,55,56)
- **尺寸变化**: 根据地图ID不同
  - 408x276: 地图17,21
  - 408x256: 地图22
  - 312x192: 地图23
  - ?x244: 地图27
  - 标准尺寸: 地图9,24,25,28,29
- **加载条件**: 根据当前地图ID动态选择

#### 2. 地图元素 (索引9,95)
- **用途**: 地图障碍物、NPC位置、传送点
- **数据格式**: 结构化二进制数据
- **解析方式**: 按固定长度记录读取
