# FD2 渲染系统逆向分析文档

本文档基于IDA MCP对FD2.EXE的逆向分析结果，详细记录了游戏的核心渲染逻辑。

## 渲染架构概述

FD2游戏使用VGA Mode 13h进行渲染：
- **分辨率**: 320x200 (256色)
- **帧缓冲**: 物理地址 0xA0000 (VGA显存段)
- **大小**: 64000字节 (320 * 200)
- **调色板**: 通过VGA DAC寄存器 (端口 0x3C6-0x3C9) 控制
- **颜色格式**: 6位RGB (0-63) 存储在DAT文件中，写入DAC时转换为8位

## 核心渲染函数

### 1. sub_4E98D - RLE图像解压缩

**地址**: 0x4E98D

**功能**: 解压缩RLE格式的图像数据到帧缓冲区

**函数签名**:
```c
char __cdecl sub_4E98D(
    __int16 *arg0,  // RLE压缩数据指针
    int arg4,       // 保留参数
    int arg8,       // 目标X偏移
    int argC,       // 目标Y偏移
    int arg10,      // 每行字节数 (320)
    int value_1     // 特殊颜色值 (-1=正常解压)
);
```

**RLE压缩格式**:
```
控制字节 b:
  b >= 192: 跳过 (b - 192 + 1) 个像素 (透明)
  128 <= b < 192: 用下一个字节填充 (b - 128 + 1) 个像素
  64 <= b < 128:  从源复制 (b - 64) 个字节
  b < 64:         用下一个字节填充 b 个像素
```

**图像尺寸**:
- RLE数据前4字节: 宽度(2字节) + 高度(2字节)
- 小端字节序 (little-endian)

**使用场景**:
- 标题画面解压缩
- 菜单项绘制
- 动画帧加载

---

### 2. sub_16886 - DAT资源绘制函数

**地址**: 0x16886

**功能**: 从DAT文件资源中解压缩并绘制到帧缓冲区

**函数签名**:
```c
char __fastcall sub_16886(
    __int32 a1,
    int a2,
    int a3,
    int a4,
    int a5,       // 目标帧缓冲偏移 (如 707969)
    int a6,       // 每行字节数 (320)
    int a7,       // FDOTHER.DAT 内存指针
    int a8        // 资源索引
);
```

**实现细节**:
```c
char __fastcall sub_16886(...) {
    sub_3702F(..., 32);  // 栈初始化
    return sub_4E98D(
        (__int16 *)(*(_DWORD *)(a7 + 4 * a8 + 6) + a7),  // 计算资源数据地址
        0,
        0,
        a5,     // 目标偏移
        a6,     // 行宽
        -1      // 正常解压
    );
}
```

**关键点**:
- 资源地址计算: `FDOTHER_ptr + *(DWORD*)(FDOTHER_ptr + 4*index + 6) + FDOTHER_ptr`
- 内部调用 `sub_4E98D` 进行RLE解压缩
- 目标偏移 `a5` 是帧缓冲的绝对偏移 (相对于0xA0000)

### 3. sub_11EB0 - 帧缓冲复制

**地址**: 0x11EB0

**功能**: 将图像数据从一个缓冲区复制到帧缓冲区 (类似memmove)

**函数签名**:
```c
int __fastcall sub_11EB0(
    __int32 a1,
    int a2,
    int a3,
    int a4,
    int a5,       // 目标帧缓冲地址 (通常 655360)
    int a6,       // 源行宽 (320)
    int a7,       // 源数据指针
    int a8,       // 源行宽
    int a9,       // 复制宽度 (320)
    int a10       // 复制高度 (200)
);
```

**使用场景**:
- 滚动动画中从scroll_buf复制200行到帧缓冲
- 动画帧的屏幕刷新

**实现**:
- 逐行复制，支持重叠区域的正确处理
- 参数控制复制的宽度、高度和步长

### 4. sub_11D40 - 调色板设置

**地址**: 0x11D40

**功能**: 设置VGA调色板和亮度

**函数签名**:
```c
void __fastcall sub_11D40(
    int a1,
    int a2,
    int a3,
    int a4,
    int a5,       // 保留 (0)
    int a6,       // 保留 (255)
    int a7        // 亮度值 (0-64)
);
```

**实现细节**:
- 通过VGA DAC寄存器端口写入颜色数据
- 亮度值控制调色板整体亮度
- 亮度 0 = 全黑 (所有颜色置0)
- 亮度 64 = 最大亮度

**使用方式**:
```c
sub_11D40(FDOTHER_DAT, a1, n99_1, 0, 0, 255, 64);  // 正常亮度
sub_11D40(v15, a1, n99_1, 0, 0, 255, 0);           // 亮度0 (黑屏)
```

### 5. sub_1F525 - 屏幕淡入

**地址**: 0x1F525

**功能**: 从黑色渐变到正常显示 (64步)

**函数签名**:
```c
int __fastcall sub_1F525(__int32 a1, int a2, int a3, int a4);
```

**实现**:
```c
int __fastcall sub_1F525(...) {
    result = sub_3702F(..., 20);
    for (n64 = 64; n64 >= 0; --n64) {
        sub_11D40(result, a2, n64, a4, 0, 255, n64);
        result = j___delay(2);
    }
    return result;
}
```

**参数说明**:
- 64步淡入，每步延迟2ms
- 总时间: 约130ms
- 通过 `sub_11D40` 逐步增加亮度

---

### 6. sub_1F882 - 屏幕淡出

**地址**: 0x1F882

**功能**: 从正常显示渐变到黑色

**实现**:
- 与 `sub_1F525` 相反的过程
- 64步淡出，每步延迟2ms
- 通过逐步降低亮度实现

### 7. sub_2DF01 - 调色板渐变

**地址**: 0x2DF01

**功能**: 在两种调色板状态之间渐变

**函数签名**:
```c
int __fastcall sub_2DF01(
    __int32 a1,
    int a2,
    int a3,
    int a4,
    int a5,       // 保留 (0)
    int a6,       // 保留 (255)
    int a7,       // 渐变步数 (当前进度)
    int base_r6,  // 基础颜色R (6位 0-63)
    int base_g6,  // 基础颜色G (6位 0-63)
    int base_b6   // 基础颜色B (6位 0-63)
);
```

**使用场景**:

**淡出到红色** (Phase 3):
```c
for (n40 = 40; n40 >= 0; --n40) {
    sub_2DF01(..., n40, 0x3Fu, 0, 0);  // 渐变到红色(63,0,0)
    j___delay(8);
}
```

**淡入菜单背景** (Phase 5):
```c
for (n40_1 = 0; n40_1 <= 40; ++n40_1) {
    sub_2DF01(..., n40_1, 0x38u, 0x3Cu, 0x3Fu);
    j___delay(8);  // 从(56,60,63)淡蓝灰色渐变到正常
}
```

### 8. sub_11DF2 - 调色板亮度叠加

**地址**: 0x11DF2

**功能**: 在6位空间中对调色板所有条目增加一个亮度值

**函数签名**:
```c
void __fastcall sub_11DF2(
    int a1,
    int a2,
    int a3,
    int a4,
    int a5,       // 保留 (0)
    int a6,       // 保留 (255)
    int a7        // 叠加值 (6位)
);
```

**使用场景**:
```c
sub_11DF2(..., 64);  // 叠加64到所有条目 (实际会饱和到63 = 最大亮度)
```

**效果**:
- 产生"变白"的调色板效果
- 用于菜单淡入前的预处理

### 9. sub_1F73F - 覆盖层特效

**地址**: 0x1F73F

**功能**: 在滚动动画中插入覆盖层画面

**函数签名**:
```c
void __fastcall sub_1F73F(
    int a1,
    int a2,
    int a3,
    int a4,
    int image_res,      // FDOTHER图像资源索引
    int palette_res,    // FDOTHER调色板资源索引
    int scroll_buf,     // 滚动缓冲指针
    int scroll_pos      // 当前滚动位置
);
```

**实现流程**:
1. 淡出到黑色 (sub_1F882)
2. 加载覆盖层调色板
3. 清屏并绘制覆盖层图像 (sub_16886)
4. 淡入 (sub_1F525)
5. 等待6个tick (sub_17AA9)
6. 淡出 (sub_1F882)
7. 恢复滚动缓冲内容
8. 恢复原始调色板
9. 淡入 (sub_1F525)

**使用场景**:
- 滚动位置450: 覆盖层#100 + 调色板#99
- 滚动位置10:  覆盖层#75 + 调色板#76

### 10. sub_1FF79 - 菜单项绘制

**地址**: 0x1FF79

**功能**: 绘制游戏主菜单项 (Start/Load/Continue)

**函数签名**:
```c
char __fastcall sub_1FF79(
    __int32 a1,
    int a2,
    int a3,
    int a4,
    int FDOTHER_DAT,  // FDOTHER内存指针
    int n3,           // 当前选中项 (-1=无高亮, 0=Start, 1=Load, 2=Continue)
    int n2            // 可见项数量 (2-4)
);
```

**实现细节**:
```c
char __fastcall sub_1FF79(..., int FDOTHER_DAT, int n3, int n2) {
    sub_3702F(..., 20);
    
    // Item 0 (Start)
    n2_1 = (n3 == 0) ? 2 : 1;  // 2=选中, 1=未选中
    sub_16886(n2_1, ..., 707969, 320, FDOTHER_DAT, n2_1);
    
    // Item 1 (Load) - 仅当n2>1时显示
    if (n2 > 1) {
        n3_1 = (n3 == 1) ? 4 : 3;
        sub_16886(n3_1, ..., 710849, 320, FDOTHER_DAT, n3_1);
    }
    
    // Item 2 (Continue) - 仅当n2>2时显示
    if (n2 > 2) {
        n5 = (n3 == 2) ? 6 : 5;
        sub_16886(n5, ..., 713729, 320, FDOTHER_DAT, n5);
    }
}
```

**菜单资源映射** (FDOTHER #7资源集):

FDOTHER #7是一个资源集，包含7张图片：

| 资源索引 | 用途 | 状态 |
|---------|------|------|
| FDOTHER #7[0] | Start | 菜单背景 |
| FDOTHER #7[1] | Start | 未选中 |
| FDOTHER #7[2] | Start | 选中 |
| FDOTHER #7[3] | Load | 未选中 |
| FDOTHER #7[4] | Load | 选中 |
| FDOTHER #7[5] | Continue | 未选中 |
| FDOTHER #7[6] | Continue | 选中 |

**菜单项屏幕位置**:

| 项目 | 帧缓冲偏移 | 计算方式 | 屏幕坐标 |
|------|-----------|---------|---------|
| Start | 707969 | 707969-655360=52609 | x=49, y=164 |
| Load | 710849 | 710849-655360=55489 | x=49, y=173 |
| Continue | 713729 | 713729-655360=58369 | x=49, y=182 |

**菜单可见性控制**:
- n2=2: 仅显示Start
- n2=3: 显示Start和Load
- n2=4: 显示全部3项

**菜单交互逻辑** (在sub_1F894中):
1. 绘制菜单 (sub_1FF79)
2. 等待键盘输入 (int386(22,...))
3. UP键 (scan code 72): 向上移动选择
4. DOWN键 (scan code 80): 向下移动选择
5. ENTER/SPACE/RIGHT (scan code 13/32/82): 确认选择
6. 确认选择后: 闪烁4次 (80ms on/off)

### 12. sub_20421 - 动画播放器

**地址**: 0x20421

**功能**: 播放ANI.DAT中的AFM动画序列

**函数签名**:
```c
void __fastcall sub_20421(
    int ani_index,      // ANI.DAT中的动画索引
    int frame_delay_ms, // 每帧延迟时间 (ms)
    int interruptible   // 是否可中断 (1=可中断, 0=不可中断)
);
```

**实现细节**:
1. 打开ANI.DAT文件
2. 查找动画索引: `fseek(4*ani_index + 6, 0)`
3. 读取动画偏移: `*(DWORD*)buf`
4. 跳转到动画数据: `fseek(offset, 0)`
5. 循环播放AFM帧
6. 每帧调用sub_4E98D解压缩到屏幕

**使用的ANI动画索引**:

| 索引 | 用途 | 延迟 | 场景 |
|------|------|------|------|
| ANI #0 | 星盘动画 | 15ms | 滚动位置25 |
| ANI #1 | 游戏标题 | 15ms | Phase 4 |
| ANI #2 | 结尾动画 | - | 未直接使用 |
| ANI #3 | 角色盖亚 | 90ms | Phase 1 |
| ANI #4 | 角色索尔 | 90ms | 滚动位置330 (第1个) |
| ANI #5 | 索尔战斗 | 50ms | 滚动位置330 (第2个) |
| ANI #6 | 角色莱汀 | 90ms | 滚动位置210 (第1个) |
| ANI #7 | 莱汀战斗 | 50ms | 滚动位置210 (第2个) |
| ANI #8 | 索尔和莱汀 | 90ms | 滚动位置110 |

## 关键内存地址

| 名称 | 地址 | 说明 |
|------|------|------|
| 帧缓冲区 | 655360 (0xA0000) | VGA Mode 13h显存 |
| 帧缓冲大小 | 64000 | 320*200字节 |
| FDOTHER.DAT指针 | 0x53E00 | 加载后的内存指针 |
| 滚动缓冲区 | malloc(320*735) | 235200字节 (5帧*147行) |

## VGA DAC寄存器

| 端口 | 功能 |
|------|------|
| 0x3C6 | 调色板掩码寄存器 |
| 0x3C7 | 读索引 |
| 0x3C8 | 写索引 |
| 0x3C9 | RGB数据 (R, G, B各1字节) |

**颜色转换**:
- DAT文件中: 6位RGB (0-63)
- VGA DAC: 6位RGB直接写入 (硬件会自动扩展到8位)
- 写入顺序: R, G, B

| 阶段 | 调色板 | 图像 | 说明 |
|------|--------|------|------|
| Phase 0 | FDOTHER #75 | FDOTHER #73 | 标题画面 |
| Phase 1 | FDOTHER #99 | ANI #3 | 开场电影 |
| Phase 2 | FDOTHER #101 | FDOTHER #69-73 | 滚动动画 |
| Phase 2.450 | FDOTHER #99 | FDOTHER #100 | 覆盖层1 |
| Phase 2.10 | FDOTHER #76 | FDOTHER #75 | 覆盖层2 |

| Phase 5 | FDOTHER #8 (+64) | FDOTHER #7 | 菜单背景 |
| Phase 6 | FDOTHER #7 | FDOTHER #1-6 | 菜单项 |

## 调色板亮度系统

**亮度值**: 0-64 (6位范围+1)

| 亮度 | 效果 |
|------|------|
| 0 | 全黑 |
| 32 | 半暗 |
| 64 | 最大亮度 |

**亮度操作函数**:
- `sub_11D40`: 直接设置亮度
- `sub_1F525`: 淡入 (亮度 0 → 64)
- `sub_1F882`: 淡出 (亮度 64 → 0)
- `sub_2DF01`: 调色板渐变到特定颜色
- `sub_11DF2`: 亮度叠加 (饱和到63)

## 滚动动画详细流程

**初始化**:
1. 分配滚动缓冲区: `malloc(320 * 735)` = 235200字节
2. 清屏: `memset(655360, 0, 64000)`
3. 加载调色板: FDOTHER #101
4. 设置亮度: 64
5. 构建滚动缓冲: 解压缩FDOTHER #69-73到缓冲区
6. 初始淡入: `sub_1F525()`

**主循环** (n535 = 535 → 0):
```
for (n535 = 535; n535 >= 0; --n535) {
    // 复制200行到屏幕
    sub_11EB0(scroll_buf + 320*n535, ..., 655360, ..., 320, 200);
    
    // 特殊位置处理
    if (n535 == 535) sub_1F525();        // 初始淡入
    if (n535 == 450) sub_1F73F(100,99);  // 覆盖层1
    if (n535 == 330) ANI#4 + ANI#5;      // 角色索尔+索尔战斗
    if (n535 == 210) ANI#6 + ANI#7;      // 角色莱汀+莱汀战斗
    if (n535 == 110) ANI#8;              // 索尔和莱汀
    if (n535 == 25)  ANI#0, break;       // 星盘动画, 退出循环
    if (n535 == 10)  sub_1F73F(75,76);   // 覆盖层2
    
    // 调色板闪烁效果
    if (n535 == dst_[n15 + 3]) {
        // 切换暗调色板 (FDOTHER #102)
        // 持续11帧后恢复 (FDOTHER #101)
    }
    
    j___delay(30);
    if (n535 == 0) j___delay(1000);
    if (键盘按键) goto 淡出到菜单;
}
```

**淡出到菜单** (Phase 3-6):
1. 淡出到红色(63,0,0) 40步
2. 播放ANI #1 (菜单介绍)
3. 加载FDOTHER #8调色板，亮度叠加64
4. 绘制菜单背景 (FDOTHER #7[0])
5. 从(56,60,63)淡入 40步
6. 显示菜单项并等待输入 (FDOTHER #7[1-6])
