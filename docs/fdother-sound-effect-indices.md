# FDOTHER.DAT 音效资源索引编号

## 概述

FDOTHER.DAT 文件包含了游戏《金庸群侠传2》的所有数字音效（samples）和 XMIDI 音乐序列（sequences）。这些资源通过索引编号进行访问，主要使用两个函数进行播放：

- **`sub_25A96`**：播放数字音效（sample），调用 AIL_start_sample
- **`sub_25B45`**：播放 XMIDI 音乐序列（sequence），调用 AIL_start_sequence

## 特殊说明

### 动态索引
某些调用使用变量作为索引（非固定值），例如：
- `sub_25A96(..., *(unsigned __int8 *)(n100 + 5), ...)` - 使用动态计算值
- `sub_25A96(..., (unsigned __int8)dst__2[n9], ...)` - 使用数组索引值

这些动态索引通常对应场景特定的音效，无法在静态分析中确定具体编号。

### 停止音效/音乐
- **索引 -1** 用于 `sub_25A96` 表示停止所有正在播放的音效
- `sub_25B45` 使用索引 3 停止音乐序列

### 资源块标识
调用中出现的标识符说明：
- `FDOTHER_DAT__0`：资源块 0
- `FDOTHER_DAT__1`：资源块 1
- `FDOTHER_DAT__5`：资源块 5
- `FDOTHER_DAT__7`：资源块 7
- `dword_5414B`：未知资源块
- `dword_54153`：未知资源块
- `dword_53B13`：未知资源块
- `dword_53EEC`：未知资源块
