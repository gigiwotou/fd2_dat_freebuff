# FDOTHER.DAT 完整资源索引编号

## 概述

FDOTHER.DAT 文件包含了游戏《金庸群侠传2》的所有数字音效（samples）和 XMIDI 音乐序列（sequences）。这些资源通过索引编号进行访问。

## 核心函数说明

### sub_111BA - 资源加载函数
```c
_BYTE *sub_111BA(__int32 a1, int a2, int a3, int a4, int a5, int a6, int a7);
```
- **a5**: 文件名（如 "FDOTHER.DAT"）
- **a6**: 已加载的资源指针（用于释放旧资源）
- **a7**: 资源索引编号（关键参数）
- 内部逻辑：`fseek(_rb_, 4 * a7 + 6, 0)` - 通过索引在文件头定位资源偏移

### sub_25A96 - 音效播放函数
```c
int sub_25A96(__int32 a1, int a2, int a3, int a4, int a5, int a6, int a7);
```
- **a1**: FDOTHER.DAT 数据指针（资源内容）
- **a6**: 资源索引编号（用于查找资源表中的偏移）
- **a7**: 循环次数（1=不循环，>1=循环播放，-1=停止所有音效）

### sub_25B45 - XMIDI 序列播放函数
```c
int sub_25B45(__int32 a1, int a2, int a3, int a4, int a5, int a6, int a7);
```
- **a1**: FDOTHER.DAT 数据指针（资源内容）
- **a6**: 资源索引编号
- **a7**: 循环次数

## 特殊说明

### 索引 78 - 游戏标题音乐
索引 78 是在 [sub_20421](file:///d:/workspace/fd2_dat_freebuff/tools/export-for-ai/decompile/20421.c#L26) 中加载的关键资源：
- 当 `a5 == 1`（播放 ANI#1 游戏标题动画）时加载
- 加载后通过 `sub_25A96` 播放 XMIDI 背景音乐
- 动画结束后使用索引 -1 停止播放

### 停止音效/音乐
- **索引 -1** 用于 `sub_25A96` 表示停止所有正在播放的音效
- `sub_25B45` 使用索引 3 停止音乐序列

- `FDOTHER_DAT__7`：资源块 7
