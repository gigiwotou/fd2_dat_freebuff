# 文字渲染逻辑完整分析

## 1. 核心函数

### 1.1 sub_15F84 - 文本渲染主函数
**地址**: 0x15F84  
**大小**: 0x564 字节  
**原型**:
```c
void __usercall sub_15F84(
    unsigned __int8 *a1@<edi>,  // 目标显存地址
    int a2,                      // 文本资源指针 (dword_53A79 或 dword_53A7D)
    int a3,                      // 文本项索引
    int n658255,                 // 初始屏幕偏移 (658255或693535)
    int a5,                      // 屏幕宽度 (320)
    int a6,                      // 渲染参数1 (205或201)
    int a7,                      // 渲染参数2 (76)
    int a8,                      // 渲染参数3 (74或0)
    int a9,                      // 行间距 (19或0)
    int a10                      // 动画标志 (1或0)
)
```

**功能**: 解析FDTXT.DAT文本数据,处理控制码,调用sub_4ED7A渲染字符

### 1.2 sub_4ED7A - 字符渲染函数
**地址**: 0x4ED7A  
**原型**:
```c
void __cdecl sub_4ED7A(
    int a1,           // 字体资源指针 (dword_53A75)
    int n10,          // 字符索引
    int n658255,      // 目标显存地址
    unsigned __int16 a4, // 屏幕宽度 (320)
    char a5,          // 颜色参数1
    char a6,          // 颜色参数2
    int a7            // 颜色参数3
)
```

**功能**: 使用16×16位图字体在VGA显存中绘制单个字符

## 2. 渲染资源

### 2.1 FDTXT.DAT - 文本资源文件
**结构**:
```
[文件头 6字节]
[索引表项0: 4字节offset, 4字节size]
[索引表项1: 4字节offset, 4字节size]
...
[数据块0]
[数据块1]
...
```

**全局变量**:
- `dword_53A7D` (0x53A7D): 存储索引0的全局文本资源
- `dword_53A79` (0x53A79): 存储动态索引的关卡文本资源

**加载方式**:
```c
// 主函数加载默认文本
dword_53A7D = sub_111BA((int)aFdtxtDat, dword_53A7D, 0);

// 根据关卡加载对应文本
dword_53A79 = sub_111BA(aFdtxtDat, dword_53A79, n17 + 1);
```

### 2.2 FDOTHER.DAT索引4 - 字体资源
**全局变量**: `dword_53A75` (0x53A75)

**加载方式**:
```c
dword_53A75 = sub_111BA((int)aFdotherDat, dword_53A75, 4);
```

**字体格式**:
- 每个字符: **32字节** (16行 × 2字节/行)
- 字符尺寸: **16×16像素**
- 位图格式: 单色位图,每行16位

## 3. 渲染流程详解

### 3.1 sub_15F84 处理流程

#### 3.1.1 初始化
```c
v11 = (__int16 *)(*(short *)(a2 + 2 * a3) + a2);
// a2 = 文本资源指针 (dword_53A79或dword_53A7D)
// a3 = 文本项索引
// 计算: 索引表项偏移 + 资源基址 = 文本数据起始位置
```

#### 3.1.2 主循环
```c
while (1) {
    v17 = *v11; // 读取当前文本项
    
    // 处理结束标记
    if (v17 == -1) {
        if (v26) {
            sub_16559(0);
            sub_16C57(0);
            sub_16B43(v26, n2);

    }
    
    // 处理换行控制码 (-2)
    if (v17 == -2) {
        if ((n1832 == 1832 || n1832 == 36887) && n3 == 3) {
            sub_16E24();
            --n3;
        }
        n658255_1 = ++n3 * a9 * a5 + n658255;
        ++v11;
        goto LABEL_50;
    }
    
    // 处理换行+清除状态 (-3)
    if (v17 == -3) {
        if ((n1832 == 1832 || n1832 == 36887) && n3 == 3) {
            sub_16E24();
            --n3;
        }
        n658255_1 = ++n3 * a9 * a5 + n658255;
        ++v11;
        if (n1832 == 1832 || n1832 == 36887)
            sub_16559(0);
        sub_16C57(1);
        a10 = 1;
    }
    
    // 处理递归调用dword_53A7D的文本 (-4)

        n658255_2 = sub_15F84(dword_53A7D, dword_53AD9, n658255_1,

        v11 = v23;

    }
    
    // 处理递归调用dword_53ADD的文本 (-5)
    if (v17 == -5) {
        n658255_2 = sub_15F84(dword_53A7D, dword_53ADD, n658255_1, 
                              a5, 205, 76, 74, 19, 1);
        v11 = v23;
        n658255_1 = n658255_2;
    }
    
    // 处理数值显示 (-6)
    if (v17 == -6) {

            if (a10)

            n658255_1 += 16; // 字符宽度16像素
        }
        goto LABEL_50;
    }
    
    // 处理头像加载控制码 (-17, -18, -19, -20)
    // ... (省略详细代码)
    
    // 3. 普通字符渲染
    sub_4ED7A(dword_53A75, v17, n658255_1, a5, a6, a7, a8);
    n658255_1 += 16; // 移动到下一个字符位置
    v11 = v23;
    if (sub_10620())
        a10 = 0;
    if (a10)

```

#### 3.1.3 换行计算
```c

// a9 = 行间距 (19像素)
```

```c
        // 字节交换 (高低字节互换)

        LOBYTE(v18) = HIBYTE(v17);
        HIBYTE(v18) = v19;
        
        n658255_3 = n658255_2;
        n16_2 = 16; // 16像素/行
        
        do { // 逐像素渲染
            v21 = __CFSHL__(v18, 1); // 左移,检查最高位
            v18 *= 2;
            
            if (v21) { // 如果该位为1,绘制像素
                *n658255_2 = v14;           // 当前行当前列
                n658255_2[a4 - 1] = v15;    // 当前行右边缘
                n658255_2[a4] = v15;        // 下一行当前列
            }
            ++n658255_2; // 移动到下一个像素
            --n16_2;
```

## 5. 显存地址映射

### 5.1 常用起始地址
- **658255** (0xA0FDF): 标准文本显示位置
- **693535** (0xA941F): 另一种文本显示位置
- **702179** (0xABBA3): 特殊文本位置

### 5.2 VGA显存布局
```
VGA显存段: 0xA0000
屏幕宽度: 320像素
屏幕高度: 200像素
每像素: 1字节 (256色调色板)
总大小: 320 × 200 = 64000字节
```

### 5.3 地址计算
```c
// 字符位置计算
显存地址 = 起始地址 + (行号 × 行间距 × 屏幕宽度) + (列号 × 字符宽度)
// 例: 第3行第5个字符
地址 = 658255 + (3 × 19 × 320) + (5 × 16)
     = 658255 + 18240 + 80
     = 676575
```

## 7. 关键技术点

### 7.1 位图字体渲染原理
1. **位图数据**: 每个字符16×16位图,每行16位(2字节)
2. **字节交换**: 读取后高低字节互换,适应渲染顺序
3. **逐位检测**: 通过左移操作检查每位是否为1
4. **像素绘制**: 如果位为1,写入调色板颜色值

### 7.2 显存写入优化
- 使用32位填充(`memset32`)快速清除背景
- 直接写入VGA显存,无中间缓冲
- 边缘像素特殊处理(右边缘和下一行)

### 7.3 动画支持
- `a10`参数控制动画开关
- `sub_10620()`: 检查是否需要停止动画
- `sub_164E8()`: 执行动画延迟
- 数值显示时也支持动画逐字显示

### 7.4 头像系统
- 控制码-17/-18从DATO.DAT加载头像
- 控制码-19/-20从dword_53A45(角色数组)加载头像
- 支持正面(1832)和侧面(36887)两种模式

## 8. 资源协同关系

```
FDTXT.DAT (文本数据)
    ↓ 加载到
dword_53A79 / dword_53A7D
    ↓ 传递给
sub_15F84 (解析文本,处理控制码)
    ↓ 调用
sub_4ED7A (字符渲染)
    ↑ 使用
dword_53A75 (FDOTHER.DAT索引4的字体位图)
    ↓ 写入
VGA显存 (0xA0000段)
    ↓ 显示
屏幕 (320×200, 256色)
```

## 10. 注意事项

1. **字符索引10**: 在sub_4ED7A中被特殊处理,跳过渲染
2. **行间距**: 通常为19像素,可根据参数a9调整
3. **颜色参数**: a5/a6/a7控制不同位置的像素颜色
4. **动画标志**: a10=1启用动画,a10=0禁用动画
5. **递归调用**: -4/-5控制码支持嵌套文本显示
6. **显存边界**: 需要注意不要超出320×200的屏幕范围
