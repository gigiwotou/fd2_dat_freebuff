# 第三层状态机详细分析

## 1. 状态机概述

第三层状态机是游戏最底层的交互状态机，负责处理场景内的用户交互逻辑。它位于场景交互循环中，通过键盘输入驱动状态转换，实现菜单导航、选项选择和场景内操作。

### 1.1 核心特点

- **输入驱动**: 基于键盘输入（方向键、Tab、回车、空格等）进行状态转换
- **菜单导航**: 支持6个选项的循环选择（n5: 0-5）
- **场景切换**: 通过Tab键在10个子场景间切换（n16_1: 0-9）
- **动画特效**: 选择确认后播放波纹/扩散动画
- **音效反馈**: 选项切换和确认时播放相应音效

### 1.2 状态变量

| 变量名 | 地址 | 类型 | 说明 |
|--------|------|------|------|
| n5 | 0x53F4A | int | 当前菜单选择项索引 (0-5) |
| n16_1 | 0x53BFB | int | 子场景/选项数量 (0-9) |
| n17 | 0x53C03 | int | 当前主场景索引 |
| n3 | 0x53A8D | int | 按键扫描码 |
| n3_4 | 0x53F52 | int | 按键计数器/动画帧 |
| byte_51AAC | 0x51AAC | char | 状态激活标志 |

## 10. 分析要点总结

1. **输入驱动**: 第三层状态机完全由键盘输入驱动，通过BIOS中断 (int386) 读取按键
2. **菜单导航**: 支持6个选项的循环选择，通过n5变量管理
3. **子场景切换**: 通过Tab键在10个子场景间切换，通过n16_1变量管理
4. **动画特效**: 选择确认后播放10帧波纹/扩散动画
5. **音效反馈**: 选项切换和确认时播放对应音效
6. **特殊场景**: 部分场景使用byte_523E7标记为特殊场景，采用不同的处理逻辑
7. **双缓冲渲染**: 使用后备缓冲区进行渲染，避免屏幕闪烁
8. **状态标志**: 通过v21变量控制是否退出场景交互循环
9. **场景类型**: 根据n17场景索引加载不同的配置和资源
10. **退出条件**: n5==2表示选择"返回"，返回false退出场景
