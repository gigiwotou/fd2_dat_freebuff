## 二、sub_15F84 核心文本渲染逻辑

### 函数签名
```c
void sub_15F84(
    unsigned __int8* a1,      // 输出缓冲区
    int arg0,                 // FDTXT.DAT指针
    int arg4,                 // 文本索引
    int n658255,             // 屏幕起始位置
    unsigned __int16 argC,    // 屏幕行距 (320)
    char arg10,               // 前景色
    char arg14,               // 背景色
    int arg18,                // 清空标志
    int arg1C,                // 行高 (19)
    int arg20)                // 特殊标志
```

### 核心流程
```c
// 1. 获取文本数据指针
v15 = (__int16*)(*(__int16*)(arg0 + 2 * arg4) + arg0);

// 2. 主循环解析
while (1) {
    n10 = *v15;  // 读取字符/控制码
    
    switch (n10) {
        case -1:  // 文本结束
            return;
            
        case -2:  // 换行
            n658255_1 = ++n3 * arg1C * argC + n658255;
            break;
            
        case -3:  // 换行+模式开启
            sub_16C57(1);
            break;
            
        case -4:  // 递归显示
            sub_15F84(..., dword_53AD9, ...);
            break;
            
        case -5:  // 递归显示
            sub_15F84(..., dword_53ADD, ...);
            break;
            
        case -6:  // 显示数字
            sprintf(v31, "%d", n999_1);
            for (i = 0; i < strlen(v31); i++) {
                sub_4ED7A(FDOTHER_DAT__6, v31[i] - 48, ...);
            }
            break;
            
        case -17: // 加载DATO.DAT类型1832
        case -18: // 加载DATO.DAT类型36887
        case -19: // 从图标加载DATO类型1832
        case -20: // 从图标加载DATO类型36887
            // 加载对话框背景...
            break;
            
        default:  // 普通字符
            sub_4ED7A(FDOTHER_DAT__6, n10, ...);
            n658255_1 += 16;
            break;
    }
    ++v15;
}
```

## 三、sub_4ED7A 字体渲染核心算法

### 函数签名
```c
void sub_4ED7A(
    int FDOTHER_DAT_ptr,   // FDOTHER.DAT索引4指针
    int char_index,        // 字符索引 (0-1823)
    int screen_addr,       // 屏幕缓冲区地址
    unsigned __int16 pitch, // 屏幕行距
    char foreground_color,  // 前景色
    char background_color,  // 背景色
    int clear_flag)        // 清空标志
```

### 渲染流程
1. **清空区域** (如果clear_flag非0)
2. **定位字体数据**: `offset = 32 * char_index + base_ptr`
3. **逐行渲染**: 16行 × 16像素
4. **位映射**: bit=1→前景色, bit=0→透明
5. **边框绘制**: 自动绘制左边框和下边框

## 四、FDTXT.DAT 文件格式

### 索引表结构
```
偏移 0-1: 索引0文本指针
偏移 2-3: 索引1文本指针
...
偏移 2*N: 索引N文本指针

文本数据: WORD数组，以-1结束
```

### 控制码系统

| 控制码 | 值 | 功能 | 参数 |
|--------|-----|------|------|
| **-1** | 结束 | 结束渲染 | 无 |
| **-2** | 换行 | 下一行开头 | 无 |
| **-3** | 换行+模式 | 换行并开启模式 | 无 |
| **-4** | 递归 | 显示FDTXT[dword_53AD9] | 无 |
| **-5** | 递归 | 显示FDTXT[dword_53ADD] | 无 |
| **-6** | 数字 | 显示n999_1 | 无 |
| **-17** | DATO | 加载类型1832 | v15[1]=索引 |
| **-18** | DATO | 加载类型36887 | v15[1]=索引 |
| **-19** | 图标DATO | 从图标加载类型1832 | v15[1]=图标索引 |
| **-20** | 图标DATO | 从图标加载类型36887 | v15[1]=图标索引 |

## 五、FDOTHER.DAT 索引4 字体格式

### 基本信息
- **索引号**: 4
- **大小**: 58,368 字节
- **字符数**: 1824个 (58368 ÷ 32 = 1824)

### 数据结构
```
每个字符32字节:
  行0: 字节 0-1 (16位)
  行1: 字节 2-3 (16位)
  ...
  行15: 字节 30-31 (16位)

字符N: 偏移 = 32 * N
```

### 字体特征
- **尺寸**: 16×16像素
- **格式**: 1位位图
- **编码**: 索引式 (0-1823)
- **渲染**: bit=1→前景色, bit=0→透明
- **边框**: 自动绘制左边框和下边框

## 十、分析总结

1. **字体位置**: FDOTHER.DAT索引4，大小58,368字节
2. **字体格式**: 16×16位图，每字符32字节
3. **字符数量**: 1824个 (0-1823)
4. **核心函数**: `sub_4ED7A` 渲染单字符，`sub_15F84` 处理文本流
5. **控制码系统**: -1到-20有特殊含义
6. **渲染方式**: 1位位图，自动绘制边框
7. **对话框系统**: 支持淡入动画和多层绘制
