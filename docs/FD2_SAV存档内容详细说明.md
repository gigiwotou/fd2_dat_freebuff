## 八、图标系统 (fdicon.b24)

### 8.1 文件结构

**头部**: 6720字节 (140个图标 × 48字节/图标)

**每个图标索引** (48字节):
- 13个DWORD值
- `[0]-[11]`: 图标相关指针/偏移
- `[12]`: 结束偏移

### 8.2 加载逻辑 (sub_11019)

```c
fseek(fdicon, 6, 0);  // 跳过6字节文件头
fread(v6, 1, 6720, fdicon);  // 读取头部

// 读取指定图标的13个DWORD

  v13[n13] = *(DWORD *)&v6[48 * icon_id + 4 * n13];

// 检查缓存
if (dword_53BDF)
{
  for (i = 0; i < dword_53BDF; ++i)
  {
    if (icon_id == dword_53B17[i])
      return i;  // 已缓存，返回索引
  }
  // 未缓存，加载到缓存
  dword_53B17[i] = icon_id;
  fseek(fdicon, v13[0], 0);
  fread(buf__3 + dword_53A61, 1, v14, fdicon);
  // 更新指针
  buf__3 += v14;
  return dword_53BDF++;

  // 第一次加载，初始化缓存
  dword_53B17[0] = icon_id;
```
