## 概述

本文档记录《炎龙骑士团2》（FD2）从启动到地图加载涉及的所有资源文件，以及每个文件的解析实现状态。

## 一、游戏流程与资源加载时序

```
游戏启动
    ↓
[INIT 状态] 加载基础资源
    ├─ FDOTHER.DAT    ✅ 已加载
    ├─ FDTXT.DAT      ✅ 已加载
    ├─ BG.DAT         ✅ 已加载
    ├─ FIGANI.DAT     ✅ 已加载
    ├─ TAI.DAT        ✅ 已加载
    └─ ANI.DAT        ✅ 已加载
    ↓
[INTRO 状态] 播放开场动画
    ├─ ANI.DAT 资源    ✅ 已实现 AFM 解码
    ├─ FDOTHER.DAT     ✅ 已实现（标题、背景等）
    └─ 资源 68-75      ✅ 已实现（开场背景）
    ↓
[MENU 状态] 显示主菜单
    ├─ FDOTHER.DAT[7]  ✅ 已实现（调色板）
    ├─ FDOTHER.DAT[6]  ✅ 已实现（菜单背景）
    └─ 菜单项资源      ⚠️ 部分实现
    ↓
[CUTSCENE 状态] 播放剧情
    ├─ 场景数据        ⚠️ 部分实现（硬编码 3 个场景）
    ├─ DATO.DAT        ❌ 未加载
    ├─ FIGANI.DAT      ❌ 未解析角色精灵
    └─ FDICON.B24      ❌ 未实现
    ↓
[BATTLE 状态] 进入地图
    ├─ FDFIELD.DAT     ✅ 已实现（Layout/Control/Event）
    ├─ FDSHAP.DAT      ✅ 已实现（瓦片集）
    ├─ FDOTHER.DAT     ✅ 已实现（调色板）
    └─ 事件数据        ⚠️ 部分实现（结构分析完成，未编码）
```

## 七、关键发现

### 7.1 资源加载模式

游戏使用统一的资源加载函数 `sub_111BA`：
```c
void* sub_111BA(const char* filename, void* prev_buf, int resource_index);
```

- `filename`: DAT 文件名
- `prev_buf`: 之前的缓冲区（用于释放）
- `resource_index`: 资源索引

### 7.2 DAT 文件格式

所有 DAT 文件使用**格式 2**：
- 字节 0-5: 魔数 "LLLLLL"
- 字节 6+: 资源偏移表（无显式计数）
- 每个偏移 4 字节（小端序 DWORD）

### 7.3 地图资源索引

每个地图使用 3 个连续资源：
- `3 * map_id`: Layout 数据
- `3 * map_id + 1`: Control 数据
- `3 * map_id + 2`: Event 数据

### 7.4 瓦片集索引

FDSHAP.DAT 中瓦片集成对出现：
- `terrain_set_id * 2`: 瓦片图像集
- `terrain_set_id * 2 + 1`: 调色板
