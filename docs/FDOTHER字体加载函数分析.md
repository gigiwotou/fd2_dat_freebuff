# FDOTHER.DAT 字体加载函数分析

## 概述

通过IDA Pro MCP分析汇编代码，发现FDOTHER.DAT包含**16x16位图字体**数据，用于游戏中文字显示。字体资源位于**索引4**处。

## 关键函数

### 1. sub_4ED7A - 字体渲染核心函数

**地址**: 0x4ED7A

**功能**: 从FDOTHER.DAT中读取字体位图数据，并将其渲染到屏幕缓冲区

**参数说明**:
- `_FDOTHER.DAT_` (arg0): FDOTHER.DAT数据指针（已加载到内存）
- `n10` (arg4): 字符索引（0-1823对应1824个字符）
- `n658255` (arg8): 目标屏幕缓冲区基地址
- `argC` (argC): 屏幕行距（pitch）
- `arg10` (arg10): 前景色/字符颜色
- `arg14` (arg14): 背景色/边框颜色
- `arg18` (arg18): 是否先清空区域（非零表示需要清空）

**C代码实现**:

```c
void __cdecl sub_4ED7A(
    int _FDOTHER.DAT_,        // FDOTHER.DAT数据指针
    int n10,                  // 字符索引（0-1823）
    int n658255,              // 屏幕缓冲区基地址
    unsigned __int16 argC,    // 屏幕行距（pitch）
    char arg10,               // 前景色（字符颜色）
    char arg14,               // 背景色（边框颜色）
    int arg18)                // 清空标志（非零=先清空）
{
  // 保存参数到全局变量
  FDOTHER_DAT__1 = _FDOTHER.DAT_;
  n10_2 = n10;
  ::n658255 = n658255;
  ::argC = argC;
  ::arg10 = arg10;
  ::arg14 = arg14;
  ::arg18 = arg18;
  
  // 步骤1: 如果需要，先清空16x16区域为背景色
  if ( (_BYTE)arg18 )
  {
    // 创建32位颜色值（用于memset32）
    BYTE1(arg18_1) = arg18;
    arg18_2 = arg18_1;
    value = arg18_1 << 16;
    LOWORD(value) = arg18_2;
    
    n658255_1 = (char *)::n658255;
    n16 = 16;
    
    // 逐行清空（16行）
    do
    {
      memset32(n658255_1, value, 4u);  // 每行清空4个32位（16字节）
      n658255_1 += argC;                // 移动到下一行
      --n16;
    }
    while ( n16 );
  }
  
  // 步骤2: 渲染字符位图（跳过字符索引10）
  if ( n10_2 != 10 )
  {
    // 定位到字体数据：偏移 = 32 * 字符索引 + FDOTHER.DAT基地址
    // 每个字符占用32字节（16行 x 2字节/行）
    v12 = (__int16 *)(32 * n10_2 + FDOTHER_DAT__1);
    
    n658255_2 = (char *)::n658255;
    arg10_1 = ::arg10;    // 前景色
    arg14_1 = ::arg14;    // 背景色
    n16_1 = 16;
    
    // 逐行处理（16行）
    do
    {
      v17 = *v12++;  // 读取一行位图数据（16位）
      
      // 字节交换（小端序调整）
      v19 = v17;
      LOBYTE(v18) = HIBYTE(v17);
      HIBYTE(v18) = v19;
      
      n16_2 = 16;
      
      // 逐像素处理（16像素）
      do
      {
        v21 = __CFSHL__(v18, 1);  // 左移，检查最高位（CF标志）
        v18 *= 2;
        
        // 如果最高位为1，绘制前景色
        if ( v21 )
        {
          *n658255_2 = arg10_1;              // 当前像素=前景色
          n658255_2[argC - 1] = arg14_1;     // 左边框=背景色
          n658255_2[argC] = arg14_1;         // 下边框=背景色
        }
        ++n658255_2;  // 移动到下一个像素
        --n16_2;
      }
      while ( n16_2 );
      
      // 移动到下一行
      n658255_2 = &n658255_3[argC];
      --n16_1;
    }
    while ( n16_1 );
  }
}
```

**字体数据格式**:

```
FDOTHER.DAT索引4的数据结构：

每个字符占用 32 字节（16行 x 2字节/行）

字符0: 偏移 0x00  (字节 0-31)
  行0: 字节 0-1   (16位位图，bit15=左，bit0=右)
  行1: 字节 2-3
  ...
  行15: 字节 30-31

字符1: 偏移 0x20  (字节 32-63)
字符2: 偏移 0x40  (字节 64-95)
...
字符N: 偏移 32*N

总字符数: 1824个
总大小: 1824 × 32 = 58,368 字节
```

**渲染原理**:
1. 每个字符是16x16像素的位图
2. 每行用16位（2字节）表示
3. 位=1的地方绘制前景色
4. 位=0的地方不绘制（透明）
5. 同时绘制左边框和下边框为背景色

### 2. sub_15F84 - 文本显示函数

**地址**: 0x15F84

**功能**: 处理文本字符串，解析控制码，调用sub_4ED7A渲染每个字符

**C代码关键逻辑**:

```c
void __usercall sub_15F84(...)
{
  // 获取文本数据指针
  v15 = (__int16 *)(*(__int16 *)(arg0 + 2 * arg4) + arg0);
  
  while ( 1 )
  {
    n10 = *v15;  // 读取当前字符/控制码
    
    // 控制码处理：
    if ( n10 == -1 )
    {
      // -1: 结束标记
      sub_16B43(v35, n2);  // 完成绘制
      JUMPOUT(0x15309);
    }
    
    if ( n10 == -2 )
    {
      // -2: 换行控制
      n658255_1 = ++n3 * arg1C * argC + n658255;
      goto LABEL_50;
    }
    
    if ( n10 == -3 )
    {
      // -3: 换行 + 开启某种模式
      sub_16C57(1);
      arg20 = 1;
    }
    
    if ( n10 == -4 )
    {
      // -4: 递归调用显示FDTXT.DAT的内容
      sub_15F84(a1, FDTXT_DAT__0, dword_53AD9, ...);
    }
    
    if ( n10 == -5 )
    {
      // -5: 递归调用显示FDTXT.DAT的内容
      sub_15F84(a1, FDTXT_DAT__0, dword_53ADD, ...);
    }
    
    if ( n10 == -6 )
    {
      // -6: 显示数字（将n999_1转换为字符串）
      sprintf(v31, "%d", n999_1);
      v37 = strlen(v31);
      
      for ( i = 0; v37 > i; ++i )
      {
        // 调用字体渲染函数
        // 字符ASCII - 48 = 字符索引 ('0'是48)
        sub_4ED7A(FDOTHER_DAT__6, 
                  (unsigned __int8)v31[i] - 48,  // 字符索引
                  n658255_1, argC, arg10, arg14, arg18);
        
        n658255_1 += 16;  // 移动到下一个字符位置（16像素宽）
      }
    }
    
    if ( n10 == -17 )
    {
      // -17: 加载DATO.DAT的某种数据
      DATO_DAT = sub_111BA(..., "DATO.DAT", ..., n39);
    }
    
    if ( n10 == -18 )
    {
      // -18: 加载DATO.DAT的另一种数据
      DATO_DAT = sub_111BA(..., "DATO.DAT", ..., ...);
    }
    
    // 默认情况：渲染普通字符
    sub_4ED7A(FDOTHER_DAT__6, n10, n658255_1, argC, arg10, arg14, arg18);
    n658255_1 += 16;  // 移动到下一个字符位置
  }
}
```

**控制码总结**:

| 控制码 | 功能 |
|--------|------|
| -1 | 文本结束 |
| -2 | 换行 |
| -3 | 换行 + 开启模式 |
| -4 | 递归显示FDTXT.DAT内容 |
| -5 | 递归显示FDTXT.DAT内容 |
| -6 | 显示数字变量 |
| -17 | 加载DATO.DAT数据（类型1832） |
| -18 | 加载DATO.DAT数据（类型36887） |
| -19 | 从图标数据加载DATO.DAT |
| -20 | 从图标数据加载DATO.DAT |
| 其他正值 | 字符索引，直接渲染 |

## FDOTHER.DAT索引4详细分析

### 基本信息

- **索引号**: 4
- **偏移**: 0x0000B7F7 (47,095)
- **大小**: 58,368 字节
- **类型**: binary（字体数据）
- **字符数量**: 1824个（58368 / 32 = 1824）

### 数据结构

```
索引4数据块结构：

偏移 0:    字符0（32字节）
偏移 32:   字符1（32字节）
偏移 64:   字符2（32字节）
...
偏移 32*N: 字符N（32字节）
...
偏移 58336: 字符1823（32字节）

每个字符16x16像素：
  行0: 字节 0-1  (16位)
  行1: 字节 2-3  (16位)
  ...
  行15: 字节 30-31 (16位)
```

### 字体特征

1. **尺寸**: 16x16像素
2. **格式**: 1位位图（单色）
3. **编码**: 索引式（通过数字索引访问）
4. **渲染**: 
   - bit=1 → 前景色
   - bit=0 → 透明
5. **边框**: 自动绘制左边框和下边框为背景色
6. **特殊处理**: 索引10的字符会被跳过（n10 != 10才渲染）

### 1. 游戏启动时加载

```c
{
```

```c

{
  // 解析文本数据
  while (读取字符)
```

## 总结

1. **字体位置**: FDOTHER.DAT索引4，大小58,368字节
2. **字体格式**: 16x16像素位图，每个字符32字节
3. **字符数量**: 1824个字符（58368 / 32 = 1824）
4. **核心函数**: sub_4ED7A负责渲染单个字符
5. **文本函数**: sub_15F84处理完整文本字符串和控制码
6. **渲染方式**: 1位位图，bit=1绘制前景色，bit=0透明
7. **字符索引**: 0-1823，其中索引10会被跳过不渲染
8. **控制码系统**: -1到-20有特殊含义（换行、递归、数字显示等）
