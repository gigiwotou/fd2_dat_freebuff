```c
void __fastcall sub_16B43(
    __int32 a1, int a2, int a3, int a4,

                  (int)v11, i, v10, v11, 
                  655360, 320, v10,
```

1. 逐步释放4层对话框图层（每层延迟10ms）

## 分析6: 文本输入

### 6.1 键盘输入检测

#### sub_10620 - 检查键盘输入

**地址**: 0x10620

```c
bool __fastcall sub_10620(
    __int32 a1, int a2, int a3, int a4)
{
  sub_3702F(a1, a2, a3, a4, 8);
  return MEMORY[0x41C] != MEMORY[0x41A];
}
```

**功能**: 检查是否有键盘输入

**原理**: 比较两个内存地址的值
- `MEMORY[0x41C]` - 当前键盘缓冲区位置
- `MEMORY[0x41A]` - 键盘缓冲区头位置
- 如果不相等，说明有按键

**返回值**:
- true: 有按键
- false: 无按键

---

### 6.2 读取键盘输入

**地址**: 0x16C57

