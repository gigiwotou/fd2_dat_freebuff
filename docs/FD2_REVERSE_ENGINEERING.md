# FD2 逆向工程与1:1移植指南

## 游戏信息

- **游戏名称**: FD2 (Flame Dragon 2 / 炎龙骑士团2)
- **原始平台**: DOS (使用 DOS4GW 扩展器)
- **分辨率**: 320x200 (256色 VGA)
- **可执行文件**: FD2.EXE
- **开发商**: 1993年, Lo Yuan Tsung (AFM动画系统作者)

## DAT文件格式

### 通用DAT格式
```
偏移  大小  说明
0     6     魔数 "LLLLLL"
6     4     资源数量 (little-endian uint32)
10    N*4   偏移表 (每个资源一个偏移)
```

### RLE压缩图像格式
```
偏移  大小  说明
0     2     宽度 (little-endian uint16)
2     2     高度 (little-endian uint16)
4     变长  RLE压缩的像素数据
```

### RLE压缩算法 (IDA sub_4E98D)
```
控制字节 b:
  b >= 192: 跳过 (b - 192 + 1) 个像素 (透明)
  128 <= b < 192: 用下一个字节填充 (b - 128 + 1) 个像素
  64 <= b < 128:  从源复制 (b - 64) 个字节
  b < 64:         用下一个字节填充 b 个像素
```

## 各DAT文件资源分布

### FDOTHER.DAT (422资源, 3.38MB)
- 资源 0-6: UI元素 (24x24图标等)
- 资源 7: 调色板 (768字节)
- 资源 8: 菜单资源
- 资源 9: 菜单元素 (62x26)
- 资源 10: 开场帧 (320x200)
- 资源 14-25: 各种UI元素
- 资源 47-52: 文本资源
- 资源 69-73: 动画帧 (320x147, 320x200)
- 资源 74: 标题画面 (320x200)
- 资源 75: 调色板 (768字节)
- 资源 76: 背景 (原始数据, 52031字节)
- 资源 77: 动画数据 (原始数据, 6492字节)
- 资源 99: 特效资源 (320x200)
- 资源 101: 菜单背景 (320x200)
- 资源 102: 菜单资源

### FDTXT.DAT (146资源, 120KB)
- 资源 0-26: 字体/文本图像 (各种尺寸)
- 其余资源: 文本数据

### FDSHAP.DAT (274资源, 3.56MB)
- 资源 1,3,5,7...: 角色精灵 (24x24 RLE图像)
- 资源 8,10,22...: 调色板/辅助数据 (1200字节)
- 资源 256x43, 256x44: 大型精灵表

### BG.DAT (234资源, 624KB)
- 资源 0-54: 战斗背景 (320x100 RLE图像)
- 资源 10-53: 小型数据 (7字节, 可能是调色板索引)

### TITLE.DAT (38资源, 23KB)
- 资源 0-5: 标题元素 (61x7, 62x7, 62x8)
- 其余: 原始数据

### DATO.DAT (554资源, 1.98MB)
- 资源 56,104,126: 16x224图像
- 其余: 原始数据 (可能是游戏逻辑数据)

### TAI.DAT (234资源, 95KB)
- 资源 3-54: 155x42图像 (可能是角色头像)
- 资源 0-2,10-12...: 小型数据 (7字节)

### FDFIELD.DAT (406资源, 243KB)
- 资源 1,2,4,5...: 各种小图像 (18x26到57x33)
- 资源 0,3,6...: 原始数据 (1171字节重复模式)

### FIGANI.DAT (1642资源, 15.3MB)
- 资源 0,2,3,5...: 角色动画帧 (4x4到17x17)
- 资源 1,4,7...: 小型数据 (3字节, 可能是帧延迟)

### ANI.DAT (46资源, 2.44MB)
- 专有 "AFM - Animation File Manager" 格式
- 1993年 Lo Yuan Tsung 开发
- 包含文本头和二进制动画数据

### FDMUS.DAT (90资源, 80KB)
- 音乐/音效数据
- 资源 1,4,6...: 小型数据 (3字节)
- 其余: 音频数据

## 开场动画流程 (sub_1F894)

1. 加载 FDOTHER.DAT 资源 77, 76, 74
2. 清空视频缓冲区 (655360 = A000:0000)
3. 加载标题 (资源 74), RLE解压到屏幕
4. 设置调色板 (资源 7), 亮度 64
5. 屏幕刷新, 视频特效 (步骤1, 30)
6. 加载资源 99
7. 清空屏幕, 设置调色板亮度0
8. 调用菜单处理 sub_20421(3, 90, 1)
9. 加载资源 101, 设置调色板
10. 分配 160 字节缓冲区
11. 加载动画帧 69-73 到缓冲区
    - 每帧 320x147 (最后一帧 320x200)
    - 总共 320x788 像素缓冲区
12. 播放 535 帧动画 (30ms/帧 = 16.05秒)
    - 帧 535: 屏幕刷新
    - 帧 450: 特效 sub_1F73F(100, 99)
    - 帧 330: 音效 sub_1F81E(4, 90, 99)
    - 帧 210: 音效 sub_1F81E(6, 90, 99)
    - 帧 110: 音效 sub_1F81E(8, 90, 99)
    - 帧 25: 菜单出现
    - 帧 10: 特效 sub_1F73F(75, 76)
    - 帧 0: 延迟 1000ms
13. 淡出 (40步, 8ms/步)
14. 延迟 100ms
15. 加载资源 7, 8
16. 显示菜单
17. 等待用户输入 (上下箭头, 回车/空格)
18. 菜单闪烁 4 次 (80ms on/off)
19. 进入游戏

## 提取工具

### extract_all.py
全面提取所有DAT文件资源:
```bash
python3 tools/extract_all.py --game game --output output/extracted
python3 tools/extract_all.py --game game --output output/extracted --dat FDOTHER.DAT
python3 tools/extract_all.py --game game --output output/extracted --images-only
```

### extract_intro.py
提取开场动画序列:
```bash
python3 tools/extract_intro.py --game game --output output/intro
```

### generate_resource_map.py
生成资源映射JSON:
```bash
python3 tools/generate_resource_map.py
```
