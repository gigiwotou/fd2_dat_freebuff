# FD2 开场场景逻辑分析

> 来源: IDA Pro MCP 逆向分析 FD2.EXE
> 日期: 2026-05-02

---

## 一、概述

用户在开始菜单选择 **Start** 选项后进入的第一个场景使用**特殊逻辑**，而非通用战斗逻辑。虽然该场景的视觉效果与战场地图相同，但流程完全不同。

---

## 二、执行流程

```
sub_25BF4 (main)
  └── sub_25EBB (游戏主循环入口)
       ├── sub_1F894 (开场动画)
       └── 用户选择 Start 后:
            ├── n17 = 0 (设置场景索引为 0)
            └── funcs_25E3A[0] → sub_3231B (开场场景专用函数)
```

### 关键代码位置

[25EBB.c:34-47](file:///d:/workspace/fd2_dat_freebuff/tools/export-for-ai/decompile/25EBB.c#L34-L47)：
```c
// 开场动画结束后，用户选择 Start
n17 = 0;  // 场景索引设置为 0

funcs_25E3A[n17]();  // 调用 funcs_25E3A[0] = sub_3231B
sub_25977(byte_51E63[n17], ...);  // 播放场景音乐
```

## 四、场景执行流程

### 4.1 初始化阶段
```c
n17 = 32;
sub_205DA(...);  // 切换到特定地图
sub_135DD(..., 3, 34);  // 触发事件 34
sub_1366A(..., 99);  // 执行脚本 99
```

### 4.2 NPC/角色初始化
```c
// 初始化 15 个角色/NPC
for (n2 = 0; n2 < 0xF; ++n2)
    sub_13185(n2, ..., 2);

// 播放对话 0
sub_15F84(..., 0, ...);
```

### 4.3 剧情动画序列
```c
// 初始化 13 个角色/NPC
for (n2_1 = 0; n2_1 < 0xD; ++n2_1)
    sub_13185(n2_1, ..., 2);

// 停止当前音乐，切换音乐 11
sub_25977(..., -1, 0);
sub_25977(..., 11, 0);

// 执行一系列剧情对话和动画
sub_1366A(..., 100);  // 脚本 100
sub_135DD(..., 0, 43);  // 触发事件 43

// 依次播放对话 2-5
sub_1366A(..., 101); sub_15F84(..., 2, ...);
sub_1366A(..., 102); sub_15F84(..., 3, ...);
sub_1366A(..., 103); sub_15F84(..., 4, ...);
sub_1366A(..., 104); sub_15F84(..., 5, ...);
```

### 4.4 战斗动画演示
```c
// 加载战斗资源，演示战斗动画
sub_10B4E(..., 1);  // 加载地图 1
sub_1366A(..., 90); sub_15F84(..., 0, ...);
sub_1366A(..., 91); sub_15F84(..., 1, ...);
sub_1366A(..., 92); sub_15F84(..., 2, ...);

// ... 继续播放对话 6-9
```

### 4.5 场景结束
```c
// 停止音乐
sub_25977(..., -1, 0);

// 切换地图，进入游戏主循环
sub_112A5(..., 0);

sub_205DA(...);  // 切换到新地图
sub_135DD(..., 4, 12);  // 触发事件 12
sub_1366A(..., 0);  // 执行脚本 0

// 最终对话和动画
sub_15F84(..., 0, ...);
sub_135DD(..., 0, 0);
sub_32999(1);  // 最后一次战斗动画
sub_32999(2);
sub_15F84(..., 1, ...);
sub_15F84(..., 2, ...);

// 进入通用地图系统
sub_134E4(...);  // 切换到对话/交互模式
sub_12D7B(..., 0);  // 设置场景状态
n6_6 = 0;  // 标记场景结束
```

## 五、与通用战场的区别

### 5.1 开场场景 (sub_3231B)

| 特性 | 说明 |
|------|------|
| 战斗循环 | **无** - 不进入战斗选择菜单 |
| 玩家输入 | **无** - 纯剧情自动播放 |
| 动画播放 | **固定顺序** - 按代码编写顺序执行 |
| 对话系统 | **线性** - 依次播放预设对话 |
| 音乐控制 | **脚本化** - 在特定节点切换音乐 |
| 场景结束 | **自动** - 播放完毕后自动进入主循环 |
| 调用函数指针 | `funcs_25E3A[0]` |

### 5.2 通用战场 (funcs_25E23)

| 特性 | 说明 |
|------|------|
| 战斗循环 | **有** - 包含完整的战斗回合系统 |
| 玩家输入 | **有** - 攻击、魔法、物品、逃跑等选项 |
| 动画播放 | **动态** - 根据战斗状态和玩家选择触发 |
| 对话系统 | **条件触发** - 根据战斗事件触发对话 |
| 音乐控制 | **事件驱动** - 战斗开始/胜利/失败切换音乐 |
| 场景结束 | **条件判断** - 根据战斗结果决定 |
| 调用函数指针 | `funcs_25E23[n17]` |

## 九、总结

1. **开场场景是专用逻辑**，使用 `sub_3231B` 函数处理
2. 虽然视觉效果与战场相同（使用战斗动画渲染），但**没有实际战斗系统**
3. 场景是**线性剧情演绎**，按固定顺序播放对话和动画
4. 场景结束后通过 `sub_12D7B` 和 `n6_6 = 0` 进入游戏主循环
5. 通用战场使用不同的函数指针表 `funcs_25E23`，包含完整的交互式战斗系统
