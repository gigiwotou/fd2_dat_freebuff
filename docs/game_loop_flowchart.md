# FD2 现代化架构 - 游戏循环流程图

## 1. 主程序入口流程

```
┌─────────────────────────────────────────────────────────┐
│                    main() [app_main.c]                   │
├─────────────────────────────────────────────────────────┤
│  1. 解析命令行参数 (--data-dir, --mods-dir, --scale)     │
│  2. SDL_Init (VIDEO | AUDIO | TIMER)                     │
│  3. 获取平台接口                                         │
│     ├─ fd2_platform_get_video()                         │
│     ├─ fd2_platform_get_audio()                         │
│     ├─ fd2_platform_get_input()                         │
│     └─ fd2_platform_get_time()                          │
│  4. 初始化平台状态                                       │
│     ├─ video_iface->init()                              │
│     ├─ audio_iface->init()                              │
│     └─ input_iface->init()                              │
│  5. 初始化游戏框架                                       │
│     └─ fd2_game_framework_init(&game)                   │
│  6. 进入主循环                                           │
│     └─ while (game.running)                             │
└─────────────────────────────────────────────────────────┘
```

## 2. 主游戏循环 (60 FPS)

```
┌──────────────────────────────────────────────────────────────┐
│                    主循环 (每帧执行)                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌─────────────────────┐                                     │
│  │ 1. 计算时间增量      │                                     │
│  │    delta = current   │                                     │
│  │    - last_time       │                                     │
│  └──────────┬──────────┘                                     │
│             │                                                │
│             ▼                                                │
│  ┌─────────────────────┐                                     │
│  │ 2. 处理SDL事件       │                                     │
│  │    while SDL_Poll    │                                     │
│  │    Event:            │                                     │
│  │    ├─ QUIT事件       │                                     │
│  │    ├─ F11全屏切换    │                                     │
│  │    └─ input_iface->  │                                     │
│  │       process_event  │                                     │
│  └──────────┬──────────┘                                     │
│             │                                                │
│             ▼                                                │
│  ┌─────────────────────────────────────────────┐            │
│  │ 3. 更新游戏框架                              │            │
│  │    fd2_game_framework_update()              │            │
│  │    ├─ input->begin_frame()                  │            │
│  │    ├─ 状态机更新 (switch state)             │            │
│  │    ├─ fd2_event_bus_process()               │            │
│  │    ├─ fd2_event_bus_advance_tick()          │            │
│  │    ├─ fd2_mod_mgr_update()                  │            │
│  │    └─ input->end_frame()                    │            │
│  └──────────┬──────────────────────────────────┘            │
│             │                                                │
│             ▼                                                │
│  ┌─────────────────────────────────────────────┐            │
│  │ 4. 渲染游戏画面                              │            │
│  │    fd2_game_framework_render()              │            │
│  │    ├─ switch (state)                        │            │
│  │    │   ├─ TITLE → render_title_screen()     │            │
│  │    │   ├─ MENU  → render_title_screen()     │            │
│  │    │   ├─ BATTLE → render_battle_screen()   │            │
│  │    │   ├─ DIALOG → render + overlay         │            │
│  │    │   └─ default → clear screen            │            │
│  └──────────┬──────────────────────────────────┘            │
│             │                                                │
│             ▼                                                │
│  ┌─────────────────────────────────────────────┐            │
│  │ 5. 上传并显示画面                            │            │
│  │    ├─ video->upload_screen(screen)          │            │
│  │    ├─ video->set_palette(palette)           │            │
│  │    └─ video->present()                      │            │
│  └──────────┬──────────────────────────────────┘            │
│             │                                                │
│             ▼                                                │
│  ┌─────────────────────────────────────────────┐            │
│  │ 6. 帧率控制 (目标60 FPS)                     │            │
│  │    frame_time = current - start             │            │
│  │    if (frame_time < 16.67ms)                │            │
│  │       time->delay_ms(16.67 - frame_time)    │            │
│  └─────────────────────────────────────────────┘            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 3. 游戏状态机 (fd2_game_framework_update)

```
┌────────────────────────────────────────────────────┐
│           fd2_game_framework_update()              │
├────────────────────────────────────────────────────┤
│                                                    │
│  input->begin_frame()                              │
│                                                    │
│  ┌──────────────────────────────────────────────┐ │
│  │ switch (game->state)                         │ │
│  │                                              │ │
│  │  FD2_GS_INIT:                                │ │
│  │    → set_state(FD2_GS_TITLE)                 │ │
│  │                                              │ │
│  │  FD2_GS_TITLE:                               │ │
│  │    ├─ 渲染标题画面                           │ │
│  │    └─ if START按下 → set_state(MENU)         │ │
│  │                                              │ │
│  │  FD2_GS_MENU:                                │ │
│  │    ├─ UP/DOWN 选择菜单项                     │ │
│  │    ├─ START → set_state(BATTLE)              │ │
│  │    └─ ESC → running = false                  │ │
│  │                                              │ │
│  │  FD2_GS_BATTLE:                              │ │
│  │    ├─ 获取输入 (A键、方向键)                 │ │
│  │    ├─ fd2_battle_update()                    │ │
│  │    │   ├─ 玩家回合 → 等待输入                │ │
│  │    │   ├─ 敌人回合 → AI决策                  │ │
│  │    │   └─ 执行行动 → 伤害计算                │ │
│  │    ├─ if 战斗结束 → 返回MENU                 │ │
│  │    └─ ESC → battle_ended = true              │ │
│  │                                              │ │
│  │  FD2_GS_DIALOG:                              │ │
│  │    ├─ fd2_dialog_update()                    │ │
│  │    ├─ A键 → 推进对话                         │ │
│  │    └─ if 对话结束 → 返回prev_state           │ │
│  │                                              │ │
│  │  FD2_GS_GAME_OVER:                           │ │
│  │    └─ START → set_state(MENU)                │ │
│  │                                              │ │
│  │  FD2_GS_QUIT:                                │ │
│  │    └─ running = false                        │ │
│  └──────────────────────────────────────────────┘ │
│                                                    │
│  fd2_event_bus_process()                           │
│  fd2_event_bus_advance_tick()                      │
│  fd2_mod_mgr_update()                              │
│                                                    │
│  input->end_frame()                                │
│                                                    │
└────────────────────────────────────────────────────┘
```

## 4. 战斗系统状态机 (fd2_battle_update)

```
┌──────────────────────────────────────────────────────┐
│              fd2_battle_update()                     │
├──────────────────────────────────────────────────────┤
│                                                      │
│  ┌────────────────────────────────────────────────┐ │
│  │ if battle_ended → return                       │ │
│  └────────────────────────────────────────────────┘ │
│                                                      │
│  ┌────────────────────────────────────────────────┐ │
│  │ FD2_BATTLE_PHASE_INIT:                         │ │
│  │    → fd2_battle_start_turn()                   │ │
│  └────────────────────────────────────────────────┘ │
│                                                      │
│  ┌────────────────────────────────────────────────┐ │
│  │ FD2_BATTLE_PHASE_PLAYER_TURN:                  │ │
│  │    ├─ if A键按下:                              │ │
│  │    │   ├─ if !targeting:                       │ │
│  │    │   │   → targeting = true                  │ │
│  │    │   │   → 显示行动菜单                      │ │
│  │    │   └─ else:                                │ │
│  │    │   → 执行行动                              │ │
│  │    │   → fd2_battle_execute_action()           │ │
│  │    ├─ if 左右键:                               │ │
│  │    │   → 切换菜单选项                          │ │
│  │    └─ 等待玩家输入                             │ │
│  └────────────────────────────────────────────────┘ │
│                                                      │
│  ┌────────────────────────────────────────────────┐ │
│  │ FD2_BATTLE_PHASE_ENEMY_TURN:                   │ │
│  │    ├─ fd2_battle_ai_select_action()            │ │
│  │    │   ├─ AI行为0 → 攻击最近敌人               │ │
│  │    │   ├─ AI行为1 → 攻击最弱敌人               │ │
│  │    │   ├─ AI行为2 → 低HP时防御                 │ │
│  │    │   └─ AI行为3 → 低HP时等待                 │ │
│  │    └─ fd2_battle_execute_action()              │ │
│  └────────────────────────────────────────────────┘ │
│                                                      │
│  ┌────────────────────────────────────────────────┐ │
│  │ 伤害动画播放期间:                              │ │
│  │    ├─ damage_animation--                       │ │
│  │    └─ if damage_animation == 0:                │ │
│  │       → fd2_battle_end_turn()                  │ │
│  │       → fd2_battle_check_end()                 │ │
│  └────────────────────────────────────────────────┘ │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 5. 伤害计算流程 (fd2_battle_calc_damage)

```
┌────────────────────────────────────────────────────┐
│         fd2_battle_calc_damage()                   │
├────────────────────────────────────────────────────┤
│                                                    │
│  输入: attacker, defender                          │
│  输出: damage, critical, miss                      │
│                                                    │
│  ┌──────────────────────────────────────────────┐ │
│  │ 1. Miss判定                                   │ │
│  │    if defender.agi > attacker.agi * 2:       │ │
│  │       miss_chance = (def.agi - att.agi*2)*5  │ │
│  │       if rand%100 < miss_chance:             │ │
│  │          → *out_miss = true                  │ │
│  │          → return 0                          │ │
│  └──────────────────────────────────────────────┘ │
│                                                    │
│  ┌──────────────────────────────────────────────┐ │
│  │ 2. 基础伤害计算                              │ │
│  │    base_damage = attacker.str * 2            │ │
│  │                - defender.def                │ │
│  │    if base_damage < 1:                       │ │
│  │       base_damage = 1                        │ │
│  └──────────────────────────────────────────────┘ │
│                                                    │
│  ┌──────────────────────────────────────────────┐ │
│  │ 3. 随机因子 (0.8 ~ 1.2)                      │ │
│  │    random_factor = 80 + rand%41              │ │
│  │    damage = (base_damage * random) / 100     │ │
│  └──────────────────────────────────────────────┘ │
│                                                    │
│  ┌──────────────────────────────────────────────┐ │
│  │ 4. 暴击判定                                   │ │
│  │    crit_chance = attacker.luck * 2           │ │
│  │    if rand%100 < crit_chance:                │ │
│  │       damage *= 2                            │ │
│  │       *out_critical = true                   │ │
│  └──────────────────────────────────────────────┘ │
│                                                    │
│  ┌──────────────────────────────────────────────┐ │
│  │ 5. 最小伤害保护                               │ │
│  │    if damage < 1:                            │ │
│  │       damage = 1                             │ │
│  └──────────────────────────────────────────────┘ │
│                                                    │
│  return damage                                     │
│                                                    │
└────────────────────────────────────────────────────┘
```

## 6. 事件系统流程

```
┌──────────────────────────────────────────────────────┐
│              事件总线 (fd2_event_bus_t)              │
├──────────────────────────────────────────────────────┤
│                                                      │
│  发布事件:                                           │
│  ┌───────────────────────────────────────────────┐  │
│  │ fd2_event_bus_publish(type, data, size):      │  │
│  │    ├─ 创建 fd2_event_t                        │  │
│  │    ├─ 设置 event.type                         │  │
│  │    ├─ 设置 event.timestamp                    │  │
│  │    ├─ 复制 event.data                         │  │
│  │    └─ 加入 pending队列                        │  │
│  └───────────────────────────────────────────────┘  │
│                                                      │
│  处理事件 (每帧调用):                                │
│  ┌───────────────────────────────────────────────┐  │
│  │ fd2_event_bus_process():                      │  │
│  │    ├─ 遍历 pending队列                        │  │
│  │    ├─ 对每个事件:                             │  │
│  │    │   └─ 遍历 subscribers                    │  │
│  │    │       └─ if sub.type匹配:                │  │
│  │    │          → sub.handler(event, data)      │  │
│  │    └─ 清空 pending队列                        │  │
│  └───────────────────────────────────────────────┘  │
│                                                      │
│  订阅事件:                                           │
│  ┌───────────────────────────────────────────────┐  │
│  │ fd2_event_bus_subscribe(type, handler, data): │  │
│  │    ├─ 创建 subscription                       │  │
│  │    ├─ sub.type = type                         │  │
│  │    ├─ sub.handler = handler                   │  │
│  │    ├─ sub.user_data = data                    │  │
│  │    └─ 加入 subscribers数组                    │  │
│  └───────────────────────────────────────────────┘  │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 7. MOD系统流程

```
┌──────────────────────────────────────────────────────┐
│              MOD管理器 (fd2_mod_mgr_t)               │
├──────────────────────────────────────────────────────┤
│                                                      │
│  初始化:                                             │
│  ┌───────────────────────────────────────────────┐  │
│  │ fd2_mod_mgr_init(mgr, mods_dir):              │  │
│  │    ├─ 扫描 mods_dir                           │  │
│  │    ├─ 对每个子目录:                           │  │
│  │    │   └─ fd2_mod_mgr_load_mod()              │  │
│  │    │       ├─ 读取 mod.json                   │  │
│  │    │       ├─ 解析 id, name, version, author  │  │
│  │    │       ├─ 创建 fd2_mod_t                  │  │
│  │    │       └─ 加入 mods数组                   │  │
│  │    └─ 返回加载的MOD数量                       │  │
│  └───────────────────────────────────────────────┘  │
│                                                      │
│  更新 (每帧调用):                                    │
│  ┌───────────────────────────────────────────────┐  │
│  │ fd2_mod_mgr_update(mgr):                      │  │
│  │    └─ 对每个已加载MOD:                        │  │
│  │       └─ if mod.update:                       │  │
│  │          → mod.update()                       │  │
│  └───────────────────────────────────────────────┘  │
│                                                      │
│  数据覆盖:                                           │
│  ┌───────────────────────────────────────────────┐  │
│  │ fd2_mod_mgr_override_data():                  │  │
│  │    ├─ 记录 dat_name, resource_index           │  │
│  │    ├─ 存储 override_data                      │  │
│  │    └─ 加入 overrides数组                      │  │
│  │                                               │  │
│  │ fd2_mod_mgr_get_override():                   │  │
│  │    ├─ 查找匹配的 dat_name+index               │  │
│  │    └─ 返回 override_data (如有)               │  │
│  └───────────────────────────────────────────────┘  │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 9. 关键数据流

```
┌─────────────────────────────────────────────────────────┐
│                    关键数据流                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  输入数据流:                                            │
│  SDL_Event → input_iface->process_event()               │
│           → fd2_input_t (pressed/held/released)         │
│           → fd2_game_framework_update()                 │
│           → 状态机处理                                  │
│                                                         │
│  渲染数据流:                                            │
│  游戏状态 → fd2_game_framework_render()                 │
│          → game->screen[320*200] (索引颜色)            │
│          → video->upload_screen()                       │
│          → video->set_palette()                         │
│          → video->present() → SDL屏幕                   │
│                                                         │
│  事件数据流:                                            │
│  游戏逻辑 → fd2_event_bus_publish()                     │
│          → pending队列                                  │
│          → fd2_event_bus_process()                      │
│          → subscribers处理                              │
│                                                         │
│  MOD数据流:                                             │
│  mod.json → fd2_mod_mgr_load_mod()                      │
│          → fd2_mod_t                                    │
│          → mod.update() (每帧)                          │
│          → 数据覆盖 (可选)                              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```
