## 🎮 游戏逻辑框架

### 1. 启动流程

```
start() → 初始化DOS环境
  ↓
_InitRtns() → 运行时初始化
  ↓
_CMain() → C主入口
  ↓
main() → 游戏主循环
```

### 2. 主循环架构

**核心函数**: `main()` (地址: 0x25BF4)

**游戏状态机**:
- **状态0**: 主菜单/标题界面
- **状态1**: 初始化场景 (sub_22E5C)
- **状态2**: 主游戏场景
- **状态-1**: 退出游戏

**主循环伪代码**:
```c
while (1) {
    v14 = sub_25977(18, 0);  // 获取游戏状态
    v15 = sub_25EBB(v14);     // 处理游戏状态

        // 状态0: 主循环处理

            i = sub_117E7(...);  // 处理输入
            if (n2_0 == 1) {
                // 初始化场景
                sub_22E5C();
            } else if (n2_0 == 2) {
                // 主游戏场景
                funcs_25E3A[n17]();  // 场景初始化
                sub_26152();          // 场景逻辑处理
                if (i) {
                    funcs_25E3A[n17]();  // 场景结束处理
                }
                sub_4E381();  // 清理
            }
        } while (!i);
    }
    
    if (v17) {
        sub_37ED8();  // 退出清理
        break;
    }
}
```

## 🔧 关键技术实现

### 1. 内存管理

- 使用标准 `malloc/free`
- 大块内存分配:
  - 64000字节: 屏幕缓冲区
  - 153216字节: 形状数据
  - 22987字节: 游戏存档数据
  - 2560字节: 场景数据

### 2. 定时器系统

- 使用 `MEMORY[0x46C]` (DOS定时器滴答计数器)
- 每秒约18.2个滴答
- 用于动画帧率控制和时间延迟

### 3. 随机数系统

```c
// 初始化随机数种子
v12 = rand() % 256;
for (i = 0; i < v12; ++i)
    sub_4EBE3();  // 随机数生成器
```

### 4. DOS中断调用

| 中断号 | 功能 | 用途 |
|--------|------|------|
| int 16h | 视频服务 | 设置显示模式 |
| int 22h | 键盘输入 | 获取按键扫描码 |
| int 21h | DOS服务 | 文件操作等 |

## 🎯 游戏流程总结

1. **启动阶段**: start() 初始化DOS环境,设置命令行参数
2. **初始化阶段**: main() 加载游戏数据,初始化随机数,设置显示模式
3. **主循环**: 
   - 检查游戏状态
   - 处理用户输入
   - 执行场景逻辑
   - 更新显示
4. **退出阶段**: 清理资源,恢复显示模式,退出程序
